An account is a GitHub or Google sign-in, written issuer.id. It owns every subject at identity.diverge.network that begins with it. Anyone who can open this page can add or remove accounts, and any agent attached to this tool can sign in as any of them. Removing an account here does not sign out what it already signed in.
