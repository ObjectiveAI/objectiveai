# The five kinds of tool, as one picture

An image prompt. The subject is the five kinds of tool an agent on this
daemon may call, each kind in its own pane, told apart by where it
lives, who keeps it running, and who may reach it. The facts are the
daemon's (2026-10-14); the style is 1950s print advertising meets
rubber-hose animation.

## Style

A full-page magazine advertisement from the mid-1950s, printed on
cream paper with visible halftone dots and slight registration drift.
A limited palette: tomato red, teal, mustard yellow, warm black, the
paper's cream. A bold brush-script headline across the top — "FIVE
KINDS OF TOOL!" — with a starburst badge in one corner reading "ALL
ON THE SAME DAEMON". The characters are drawn in the rubber-hose
manner: noodle limbs with no elbows or knees, white four-fingered
gloves, pie-cut eyes, a bounce in every pose. Every machine is a
cheerful appliance with a face. Five panes arranged in a grid — two
across the top, three across the bottom, or one wide pane above four —
each with a small typeset caption in a condensed sans-serif, and a
thin hand-ruled border. No real product names, no logos, no brands.

## The agent

The same agent appears in every pane so the reader can compare: a
little round robot with a derby hat, a bow tie, and a suitcase labeled
"AGENT". Its container is a cardboard box it stands in, with "THE
AGENT'S CONTAINER" stenciled on the side.

## Pane 1 — Harness tools

Caption: "HARNESS TOOLS — built right in!"

The agent has opened its own chest like a cabinet, and inside are its
built-in tools: a tiny typewriter, a magnifying glass, a wrench, a file
folder. They are part of the agent's own program — the harness it runs
in — and never leave the box. Nothing else is in the pane: no wires
out, no second machine, no daemon. A small sign on the box reads "NO
ASSEMBLY REQUIRED". This is the only kind the daemon does not run,
keep, or know by name.

## Pane 2 — Transient standalone tools

Caption: "TRANSIENT STANDALONE TOOLS — open while you're here!"

A separate little shop on wheels, a pop-up cart with a striped awning,
parked next to the agent's box. The agent reaches over to use it. The
cart's sign flips between "OPEN" and "CLOSED" on a spring: it runs
only while something uses it — an attached agent at work, a visitor on
the line, a file being moved — and folds up the moment the last user
walks away. A telephone line runs from the cart to the edge of the
pane, where a second, differently colored agent from ANOTHER DAEMON is
calling in through a candlestick phone: outside agents may connect to
a standalone tool. The cart was made by hand from a blueprint pinned
to its side labeled "TEMPLATE".

## Pane 3 — Service standalone tools

Caption: "SERVICE STANDALONE TOOLS — kept running day and night!"

The same shop, but as a permanent diner with a neon sign that says
"OPEN 24 HOURS" and a plume of smoke from the chimney. Two or three
agents sit at the counter, each tied to the diner by a ribbon labeled
"ATTACHED"; the same outside agent from another daemon is on the
telephone line again. A clock on the wall has a sign under it: "THE
CLOCK ONLY RUNS WHEN NOBODY'S HERE" — the tool is kept running while
any agent is attached or any caller is on the line, and only once the
last leaves does the idle clock count it down and close the diner. The
same blueprint is pinned up, now stamped "MODE: SERVICE".

## Pane 4 — Transient dependency tools

Caption: "TRANSIENT DEPENDENCY TOOLS — packed for one trip!"

A small machine strapped to the agent's own suitcase with a leather
belt, like luggage. A short cable runs from the machine into the
agent's box, with a tag reading "MOUNTS THE AGENT'S OWN FILES". The
agent's own blueprint — its IMAGE — is unrolled beside it, and the
machine is drawn in a dotted outline on that blueprint: the agent's
program declared it, and the daemon built it the moment the agent
started. A luggage tag reads "ONE RUN ONLY": it lives exactly as long
as this one run of this one agent, and is thrown away at the end. The
telephone line from the earlier panes is drawn cut, with a small sign:
"NO OUTSIDE CALLS" — nobody from another daemon can reach it.

## Pane 5 — Service dependency tools

Caption: "SERVICE DEPENDENCY TOOLS — one for the whole block!"

A shared appliance in the middle of a small neighborhood — a
water-cooler or a jukebox with a face — and several agents gathered
around it, each tied to it by an "ATTACHED" ribbon. A signpost beside
it has three arrows, "INSTANCE", "TEMPLATE", "GLOBAL", and one is lit:
how far it is shared is its SCOPE, declared on the image's blueprint,
which is pinned to the machine stamped "MODE: SERVICE". It mounts
nothing of anyone's: no cable into any box. The same wall clock with
the same sign — it is kept while any agent is attached and counted
down only once none is. The telephone line is cut here too: "NO
OUTSIDE CALLS".

## The differences, in one glance

Three visual rules carry the distinctions, and every pane obeys them:

- **Where it lives.** Inside the agent's box (harness); its own
  building beside the box (standalone); strapped to the agent or shared
  in the street, built from the agent's own blueprint (dependency).
- **What keeps it running.** Nothing — it is the agent (harness); use,
  with a spring-loaded sign (transient standalone); attachment and the
  idle clock, with the neon sign (service standalone); the agent's one
  run, with the luggage tag (transient dependency); attachment and the
  idle clock, shared by scope (service dependency).
- **Who may reach it.** Only the agent (harness, both dependency
  kinds, the cut telephone line); the agent and callers from other
  daemons (both standalone kinds, the live telephone line).
