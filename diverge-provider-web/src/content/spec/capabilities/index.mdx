---
title: 'Capabilities'
summary: "The traits each side implements: what a caller supplies to answer a provider's asks, and what a provider supplies to serve a caller's."
order: 8
---

The protocol reaches things neither end's SDK can know — the caller's
MCP servers and database, the provider's container runtime and
storage — so each half names capability traits the implementer
supplies. Nothing in the SDK implements any of them: the SDK is the
protocol's machinery, and these traits are the seams where a real
caller and a real provider attach.
