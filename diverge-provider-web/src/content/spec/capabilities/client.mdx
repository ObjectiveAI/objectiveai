---
title: 'What a caller supplies'
summary: "Five proxies that answer a provider's asks — MCP, OCI, commands, Postgres, laboratory admission — plus the judge of a dialling provider's credential."
order: 1
---

A caller answers what a provider's containers need: an MCP proxy
forwarding tool calls to servers the provider cannot see, an OCI proxy
serving caller-held images, a command proxy running what a plugin asks
in the caller's own CLI, a Postgres proxy splicing plugin connections
onto the caller's database, and an authorizer deciding which
connectors may join the caller's laboratories. A sixth trait judges
the credential of a provider that dialled in, answering only yes or
no — a caller derives no identity from its provider.
