---
title: 'version'
summary: 'Ask what protocol a provider speaks; the answer is the specification revision it was built against.'
order: 11
---

The request carries nothing and the response is a bare string: the
version of the `diverge-provider-sdk` the provider was compiled with,
which is also this specification's revision scheme. It is the one
question a provider can answer without supplying anything of its own.
