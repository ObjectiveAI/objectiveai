The agent kind whose `upstream` member is `"codex"`, read under the layer's [notation](/endpoints/#notation).

```rust
pub struct Agent {
    /// The discriminator. Always "codex".
    pub upstream: Upstream,
    /// The model to run.
    pub model: String,
    /// How much effort to spend reasoning.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub effort: Option<Effort>,
    /// Whether the model may search the web — a capability of the
    /// upstream rather than a tool.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub web_search_enabled: Option<bool>,
}

#[serde(rename_all = "snake_case")]
pub enum Upstream {
    Codex,
}

#[serde(rename_all = "snake_case")]
pub enum Effort {
    Low,
    Medium,
    High,
    Xhigh,
    Max,
}
```
