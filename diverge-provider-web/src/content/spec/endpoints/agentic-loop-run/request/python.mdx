The agent kind whose `upstream` member is `"python"`, read under the layer's [notation](/endpoints/#notation).

A Python agent is source code the server executes, and its resource
requirements are the client's to state — the source is opaque until it
runs, and the numbers are needed before it does.

```rust
pub struct Agent {
    /// The discriminator. Always "python".
    pub upstream: Upstream,
    /// The source, verbatim. Never normalized: whitespace is
    /// significant in Python.
    pub python: String,
    /// Memory ceiling, in bytes, interpreter included. Not a hint:
    /// a process that exceeds it is killed.
    pub memory: u64,
    /// Writable-disk ceiling, in bytes. What the run writes over its
    /// image; the image's own layers are not counted, and neither is
    /// what the requirements install.
    pub disk: u64,
    /// Third-party packages the source needs: distribution name to
    /// version constraint. A map, so one package cannot carry two
    /// contradictory constraints. Absent and empty are equivalent.
    #[serde(default, skip_serializing_if = "IndexMap::is_empty")]
    pub requirements: IndexMap<String, Version>,
}

#[serde(rename_all = "snake_case")]
pub enum Upstream {
    Python,
}

/// One version constraint: an operator and a PEP 440 version,
/// held apart so the operator is a closed set rather than a
/// prefix to parse. "2.31.0", not ">=2.31.0".
pub struct Version {
    pub operator: VersionOperator,
    pub version: String,
}

/// The comparisons of PEP 440. `===`, arbitrary equality, is
/// not among them.
pub enum VersionOperator {
    #[serde(rename = "==")]
    Equal,
    #[serde(rename = "!=")]
    NotEqual,
    #[serde(rename = ">=")]
    GreaterEqual,
    #[serde(rename = ">")]
    Greater,
    #[serde(rename = "<=")]
    LessEqual,
    #[serde(rename = "<")]
    Less,
    #[serde(rename = "~=")]
    Compatible,
}
```

The operators compare as
[PEP 440](https://peps.python.org/pep-0440/) defines them.
