The container deployed for an agent whose `upstream` is
`"python"` — the kind defined in
[Python](/endpoints/agentic-loop-run/request/python/).


| Property | Value |

| Memory | the request's `memory` member |
| Disk | the request's `disk` member |

The asymmetry is deliberate. For the other three kinds the image is a
known program doing a known job, and its appetite is a property of
the image; here the image is an interpreter, and what actually runs
arrived with the request. Its author is the only party who knows what
it needs, so the ceilings are the caller's stated numbers — read, not
advisory: a process that exceeds its memory ceiling is killed rather
than told to try something else.
