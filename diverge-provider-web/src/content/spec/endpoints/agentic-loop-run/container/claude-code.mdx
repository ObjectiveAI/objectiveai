| Memory | 2,147,483,648 bytes (2 GiB) |
| Disk | 4,294,967,296 bytes (4 GiB) |

The memory ceiling is the container's whole allowance, runtime
included. The disk ceiling is what the container may write over its
image; the image's own layers are not counted.
