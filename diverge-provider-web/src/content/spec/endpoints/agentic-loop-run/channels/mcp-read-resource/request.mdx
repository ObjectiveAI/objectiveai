The channel request's payload is the exchange tag byte `3`
followed by the JSON serialization of the params of `resources/read` as defined by the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25).

No JSON-RPC envelope is present: no `jsonrpc`, no `id`, no `method`.
The channel is the envelope, and the tag is the method.
