Channel tag `3`. Read one of the client's resources. The exchange is the `resources/read` request of
the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25), carried outside JSON-RPC: the method is designated by the
channel tag, and the payloads carry only the params and the result.

One [request](/endpoints/agentic-loop-run/channels/mcp-read-resource/request/),
one answering
[response](/endpoints/agentic-loop-run/channels/mcp-read-resource/response/),
then the channel's finish.
