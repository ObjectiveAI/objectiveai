The channel's one answering response has as its payload a single tag
byte followed by a JSON text.

| Tag | Payload |
|-----|---------|
| `0` | The result of `resources/read`, as defined by the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25). |
| `1` | The JSON-RPC error object as MCP defines it: `code` (integer), `message` (string), `data` (any JSON value, optional). |

Either answer is followed by the channel's finish. An error under tag
`1` is the MCP server's own refusal, relayed whole — its `code` is
content, not decoration. A channel that finishes with no response
preceding the finish states that the exchange could not be served at
all, which is distinct from either answer.
