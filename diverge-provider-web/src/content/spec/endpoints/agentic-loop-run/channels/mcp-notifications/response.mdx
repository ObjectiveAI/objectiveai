Each response's payload is a single tag byte followed by a JSON text.

| Tag | Payload |
|-----|---------|
| `0` | One server notification, as defined by the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25). |
| `1` | The JSON-RPC error object as MCP defines it: `code` (integer), `message` (string), `data` (any JSON value, optional). |

Type definitions, in [rmcp](https://docs.rs/rmcp/3.1.2/rmcp/) 3.1.2, the MCP implementation this revision builds against: [`rmcp::model::ServerNotification`](https://docs.rs/rmcp/3.1.2/rmcp/model/enum.ServerNotification.html); [`rmcp::model::ErrorData`](https://docs.rs/rmcp/3.1.2/rmcp/model/struct.ErrorData.html).

- **The stream.** Zero or more responses under tag `0`, in the order
  the notifications occurred, until the channel's finish.
- **An error is final.** A response under tag `1` states that no
  further notifications will be relayed, and why; it is the channel's
  final response, and the finish follows it.
- The channel's finish with no response preceding it states, as
  everywhere, that the exchange could not be served.
