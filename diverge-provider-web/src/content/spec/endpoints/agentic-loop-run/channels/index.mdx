Most [channels](/frames/channels/) on this endpoint are opened by
the server. Five carry one exchange each of the [Model Context
Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25), revision 2025-11-25, whose payload types this layer
incorporates by reference.

A channel request's payload is a single tag byte designating the
exchange, followed by the exchange's request content. The client
answers on channel responses whose payloads are defined per exchange.

| Tag | Exchange |
|-----|----------|
| `0` | [tools/list](/endpoints/agentic-loop-run/channels/mcp-list-tools/) |
| `1` | [resources/list](/endpoints/agentic-loop-run/channels/mcp-list-resources/) |
| `2` | [tools/call](/endpoints/agentic-loop-run/channels/mcp-call-tool/) |
| `3` | [resources/read](/endpoints/agentic-loop-run/channels/mcp-read-resource/) |
| `4` | [Notifications](/endpoints/agentic-loop-run/channels/mcp-notifications/) |

Four of the five are answered exactly once; notifications is a stream.
In every case, a channel that finishes with no response preceding the
finish states that the exchange could not be served.

## Postgres

A database connection the container opens on port `8082` (see
[Container](/endpoints/agentic-loop-run/container/)) is carried as
**two channels**, one opened by each party, because only a responder
ends a channel and a connection must be endable from both sides.

- The server opens a channel with tag `9`, whose payload is one
  32-bit big-endian **connection id** of the server's choosing,
  unique among the connections open in the scope. The client answers
  with the bytes the database says, verbatim, never parsed, one
  response per piece, for as long as the connection lives; its finish
  states that the database closed the connection. A finish with no
  response preceding it states that the client declines to dial.
- The client, having taken that request, opens a channel with tag `2`
  whose payload quotes the same connection id. The server answers
  with the bytes the container writes, likewise verbatim, and its
  finish states that the container's socket ended.

Several connections run at once, each its own pair; frames of
different connections interleave freely. Nothing on either channel is
framed as a message: a PostgreSQL message larger than one frame spans
several, and each end reassembles as it would from a socket.
