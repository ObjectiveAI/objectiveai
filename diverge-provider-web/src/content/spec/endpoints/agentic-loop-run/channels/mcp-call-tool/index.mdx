Channel tag `2`. Invoke one of the client's tools. The exchange is the `tools/call` request of
the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25), carried outside JSON-RPC: the method is designated by the
channel tag, and the payloads carry only the params and the result.

One [request](/endpoints/agentic-loop-run/channels/mcp-call-tool/request/),
one answering
[response](/endpoints/agentic-loop-run/channels/mcp-call-tool/response/),
then the channel's finish.
