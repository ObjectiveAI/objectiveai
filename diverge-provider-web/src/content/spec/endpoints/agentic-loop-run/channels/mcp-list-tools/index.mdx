Channel tag `0`. List the tools the client's MCP servers offer. The exchange is the `tools/list` request of
the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25), carried outside JSON-RPC: the method is designated by the
channel tag, and the payloads carry only the params and the result.

One [request](/endpoints/agentic-loop-run/channels/mcp-list-tools/request/),
one answering
[response](/endpoints/agentic-loop-run/channels/mcp-list-tools/response/),
then the channel's finish.
