The channel request's payload is the exchange tag byte `0`
followed by the JSON serialization of the paginated request parameters of `tools/list` as defined by the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25), or the JSON literal `null` when the agent supplied no parameters.

No JSON-RPC envelope is present: no `jsonrpc`, no `id`, no `method`.
The channel is the envelope, and the tag is the method.
