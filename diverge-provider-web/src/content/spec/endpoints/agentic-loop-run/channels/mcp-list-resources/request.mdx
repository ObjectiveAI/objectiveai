The channel request's payload is the exchange tag byte `1`
followed by the JSON serialization of the paginated request parameters of `resources/list` as defined by the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25), or the JSON literal `null` when the agent supplied no parameters.

Type definitions, in [rmcp](https://docs.rs/rmcp/3.1.2/rmcp/) 3.1.2, the MCP implementation this revision builds against: [`rmcp::model::PaginatedRequestParams`](https://docs.rs/rmcp/3.1.2/rmcp/model/struct.PaginatedRequestParams.html).

No JSON-RPC envelope is present: no `jsonrpc`, no `id`, no `method`.
The channel is the envelope, and the tag is the method.
