Channel tag `1`. List the resources the client's MCP servers offer. The exchange is the `resources/list` request of
the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25), carried outside JSON-RPC: the method is designated by the
channel tag, and the payloads carry only the params and the result.

One [request](/endpoints/agentic-loop-run/channels/mcp-list-resources/request/),
one answering
[response](/endpoints/agentic-loop-run/channels/mcp-list-resources/response/),
then the channel's finish.
