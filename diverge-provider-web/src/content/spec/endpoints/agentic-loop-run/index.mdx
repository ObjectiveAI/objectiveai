Endpoint tag `0`. The client requests the execution of an **agentic
loop**: the server runs the requested agent and streams what the agent
produces back to the client. While the loop runs, the agent's own
requests — tool calls above all — travel to the client over
server-opened channels; the client answers them, and the answers reach
the agent.

- **The exchange.** The [request](/endpoints/agentic-loop-run/request/)
  opens the scope. The scope's
  [responses](/endpoints/agentic-loop-run/response/) are the loop's
  chunks; a response carrying an error is the scope's final response.
  The response finish ends the scope.
- **The container.** The server executes each run in a container it
  deploys — one image per agent kind, fixed resources, and three
  in-container ports, stated in
  [Container](/endpoints/agentic-loop-run/container/).
- **The channels.** Every channel on this endpoint is opened by the
  server; the client opens none. The channels are the five exchanges
  of the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25), enumerated in
  [Channels](/endpoints/agentic-loop-run/channels/).
- **Resumption.** A loop may be resumed: the server may close its
  responses with a continuation — its own state, as raw bytes — and
  on a subsequent request it fetches that continuation back from the
  client, which answers with the bytes it kept, or with nothing for a
  fresh start. The mechanics are defined with the
  [response](/endpoints/agentic-loop-run/response/) and the
  [request](/endpoints/agentic-loop-run/request/).
