The request's payload is the endpoint tag byte `0` followed by a JSON
text (UTF-8, [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259))
whose top-level value is an object with the following members.

| Member | Type | Presence | Meaning |
|--------|------|----------|---------|
| `agent` | object | required | The agent to run, and its parameters. One of the four kinds below. |
| `prompt` | array | required | The input for this turn: an array of content blocks as defined by the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25). A prompt, not a conversation — what came before is the server's state, reached through `continuation`. |
| `continuation` | string | optional | Resume the loop named by this token, previously issued in a [continuation chunk](/endpoints/agentic-loop-run/response/). Opaque to the client. |

A resumption is this same request with `continuation` present; it is
not a distinct request form, and the agent's parameters may differ
between turns.

## The agent

The `agent` object is one of four kinds, discriminated by its
`upstream` member — the object carries no other wrapper. The values of
`upstream` are `"openrouter"`, `"claude_code"`, `"codex"`, and
`"python"`.

### `openrouter`

| Member | Type | Presence |
|--------|------|----------|
| `upstream` | `"openrouter"` | required |
| `model` | string | required |
| `top_logprobs` | integer | optional |
| `frequency_penalty` | number | optional |
| `logit_bias` | object: token → integer bias | optional |
| `max_completion_tokens` | integer | optional |
| `presence_penalty` | number | optional |
| `stop` | string, or array of strings | optional |
| `temperature` | number | optional |
| `top_p` | number | optional |
| `max_tokens` | integer | optional |
| `min_p` | number | optional |
| `provider` | object, tabulated below | optional |
| `reasoning` | object, tabulated below | optional |
| `repetition_penalty` | number | optional |
| `top_a` | number | optional |
| `top_k` | integer | optional |
| `verbosity` | `"low"` \| `"medium"` \| `"high"` \| `"max"` | optional |
| `context_compression` | `"middle_out"` | optional |

#### `provider`

Constrains upstream routing.

| Member | Type | Presence |
|--------|------|----------|
| `allow_fallbacks` | boolean | optional |
| `require_parameters` | boolean | optional |
| `order` | array of provider names (strings) | optional |
| `only` | array of provider names (strings) | optional |
| `ignore` | array of provider names (strings) | optional |
| `quantizations` | array drawn from `"int4"`, `"int8"`, `"fp4"`, `"fp6"`, `"fp8"`, `"fp16"`, `"bf16"`, `"fp32"`, `"unknown"` | optional |

#### `reasoning`

Configures reasoning output.

| Member | Type | Presence |
|--------|------|----------|
| `enabled` | boolean | optional |
| `max_tokens` | integer | optional |
| `effort` | `"none"` \| `"minimal"` \| `"low"` \| `"medium"` \| `"high"` \| `"xhigh"` | optional |
| `summary_verbosity` | `"auto"` \| `"concise"` \| `"detailed"` | optional |

The semantics of these parameters are those of the OpenRouter API;
this specification fixes their names, types, and placement.

### `claude_code`

| Member | Type | Presence |
|--------|------|----------|
| `upstream` | `"claude_code"` | required |
| `model` | string | required |
| `thinking` | boolean | optional |
| `effort` | `"low"` \| `"medium"` \| `"high"` \| `"xhigh"` \| `"max"` | optional |

### `codex`

| Member | Type | Presence |
|--------|------|----------|
| `upstream` | `"codex"` | required |
| `model` | string | required |
| `effort` | `"low"` \| `"medium"` \| `"high"` \| `"xhigh"` \| `"max"` | optional |
| `web_search_enabled` | boolean | optional |

### `python`

A Python agent is source code the server executes, and its resource
requirements are the client's to state — the source is opaque until it
runs, and the numbers are needed before it does.

| Member | Type | Presence | Meaning |
|--------|------|----------|---------|
| `upstream` | `"python"` | required | |
| `python` | string | required | The source, verbatim. |
| `memory` | integer | required | Memory ceiling, in bytes. |
| `disk` | integer | required | Writable-disk ceiling, in bytes. |
| `requirements` | object: package name → version constraint, tabulated below | optional | The packages the source imports. Absent and empty are equivalent. One constraint per package: a name cannot appear twice, so contradictory constraints are unrepresentable. |

#### Values of `requirements`

Each value is one version constraint, split into an operator and a
version so the operator is a closed set rather than a prefix to parse.

| Member | Type | Presence |
|--------|------|----------|
| `operator` | `"=="` \| `"!="` \| `">="` \| `">"` \| `"<="` \| `"<"` \| `"~="` | required |
| `version` | string: a [PEP 440](https://peps.python.org/pep-0440/) version, without the operator — `"2.31.0"`, not `">=2.31.0"` | required |

The operators compare as PEP 440 defines them. `===`, arbitrary
equality, is not among them.
