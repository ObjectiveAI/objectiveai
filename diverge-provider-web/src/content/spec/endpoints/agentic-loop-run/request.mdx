The request's payload is the endpoint tag byte `0` followed by a JSON
text (UTF-8, [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259))
whose top-level value is defined by the following declaration, read
under the layer's [notation](/endpoints/#notation).

```rust
pub struct Request {
    /// What to run, and how to sample it.
    pub agent: Agent,
    /// The input for this turn: MCP content blocks.
    pub prompt: Vec<ContentBlock>,
    /// Resume the loop this token names.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub continuation: Option<String>,
}
```

Type definitions, in [rmcp](https://docs.rs/rmcp/3.1.2/rmcp/) 3.1.2, the MCP implementation this revision builds against: [`rmcp::model::ContentBlock`](https://docs.rs/rmcp/3.1.2/rmcp/model/enum.ContentBlock.html).

- **A prompt, not a conversation.** `prompt` is this turn's input,
  and the server does not rewrite it. What came before is the
  server's state, reached through `continuation`.
- **Resumption is the same request.** A resumption is this request
  with `continuation` present — the token previously issued in a
  [continuation chunk](/endpoints/agentic-loop-run/response/) — not a
  distinct request form, and the agent's parameters may differ between
  turns. The token is opaque to the client.

## The agent

The agent is one of four kinds, discriminated by each kind's constant
`upstream` member — the union is untagged, so an agent goes on the
wire as its parameters and nothing more.

```rust
#[serde(untagged)]
pub enum Agent {
    Openrouter(openrouter::Agent),
    ClaudeCode(claude_code::Agent),
    Codex(codex::Agent),
    Python(python::Agent),
}
```

### `openrouter`

```rust

pub enum Upstream {

}

/// One stop sequence, or several.

    Low,
    Medium,
    High,
    Max,

    MiddleOut,
}

/// Constrains upstream routing.
pub struct Provider {
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub allow_fallbacks: Option<bool>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub require_parameters: Option<bool>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub order: Option<Vec<String>>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub only: Option<Vec<String>>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub ignore: Option<Vec<String>>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub quantizations: Option<Vec<ProviderQuantization>>,
}

#[serde(rename_all = "snake_case")]
pub enum ProviderQuantization {
    Int4,
    Int8,
    Fp4,
    Fp6,
    Fp8,
    Fp16,
    Bf16,
    Fp32,
    Unknown,

/// Configures reasoning output.
pub struct Reasoning {
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub enabled: Option<bool>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub max_tokens: Option<u64>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub effort: Option<ReasoningEffort>,
    #[serde(default, skip_serializing_if = "Option::is_none")]

pub enum ReasoningEffort {

```

The semantics of these parameters are those of the OpenRouter API;
this specification fixes their names, types, and placement.

### `python`

A Python agent is source code the server executes, and its resource
requirements are the client's to state — the source is opaque until it
runs, and the numbers are needed before it does.

```rust
pub struct Agent {
    /// The discriminator. Always "python".
    pub upstream: Upstream,
    /// The source, verbatim. Never normalized: whitespace is
    /// significant in Python.
    pub python: String,
    /// Memory ceiling, in bytes, interpreter included. Not a hint:
    /// a process that exceeds it is killed.
    pub memory: u64,
    /// Writable-disk ceiling, in bytes. What the run writes over its
    /// image; the image's own layers are not counted, and neither is
    /// what the requirements install.
    pub disk: u64,
    /// Third-party packages the source needs: distribution name to
    /// version constraint. A map, so one package cannot carry two
    /// contradictory constraints. Absent and empty are equivalent.
    #[serde(default, skip_serializing_if = "IndexMap::is_empty")]
    pub requirements: IndexMap<String, Version>,
}

#[serde(rename_all = "snake_case")]
pub enum Upstream {
    Python,
}

/// One version constraint: an operator and a PEP 440 version,
/// held apart so the operator is a closed set rather than a
/// prefix to parse. "2.31.0", not ">=2.31.0".
pub struct Version {
    pub operator: VersionOperator,
    pub version: String,
}

/// The comparisons of PEP 440. `===`, arbitrary equality, is
/// not among them.
pub enum VersionOperator {
    #[serde(rename = "==")]
    Equal,
    #[serde(rename = "!=")]
    NotEqual,
    #[serde(rename = ">=")]
    GreaterEqual,
    #[serde(rename = ">")]
    Greater,
    #[serde(rename = "<=")]
    LessEqual,
    #[serde(rename = "<")]
    Less,
    #[serde(rename = "~=")]
    Compatible,
}
```

The operators compare as
[PEP 440](https://peps.python.org/pep-0440/) defines them.
