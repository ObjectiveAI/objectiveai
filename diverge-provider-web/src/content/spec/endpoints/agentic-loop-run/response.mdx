Each response's payload is a single tag byte followed by a JSON text,
read under the layer's [notation](/endpoints/#notation).

```rust
pub enum Response {
    /// Tag 0. One piece of the loop's output.
    Chunk(AgenticLoopChunk),
    /// Tag 1. The scope's final response.
    Error(Error),
}

/// An arbitrary JSON value, the server's to compose. This
/// specification does not constrain it.
pub struct Error(pub serde_json::Value);
```

- **An error is terminal.** A response bearing tag `1` is the scope's
  final response; the response finish follows it.
- **Chunks are ordered.** The chunks of one scope form one stream, in
  the order sent.

## Chunks

A chunk is one of ten kinds. The union is untagged: each kind is
discriminated by its own constant `type` member, and goes on the wire
as its members alone.

```rust
#[serde(untagged)]
pub enum AgenticLoopChunk {
    AssistantReasoning(AssistantReasoningChunk),
    AssistantTextContent(AssistantTextContentChunk),
    AssistantImageContent(AssistantImageContentChunk),
    AssistantAudioContent(AssistantAudioContentChunk),
    AssistantToolCall(AssistantToolCallChunk),
    AssistantRefusal(AssistantRefusalChunk),
    ToolResponse(ToolResponseChunk),
    Usage(UsageChunk),
    Notification(NotificationChunk),
    Continuation(ContinuationChunk),
}
```

`TextContent`, `ImageContent`, `AudioContent`,
`CallToolRequestParams`, `CallToolResult`, and `MetaObject` are the
types of the
[Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-11-25),
incorporated by reference. Where a chunk flattens one of them, the
MCP type's members appear directly in the chunk's object.

### `assistant_reasoning`, `assistant_text_content`, `assistant_refusal`

Reasoning text, answer text, and refusal text the agent produced —
one shape, three discriminants.

```rust
pub struct AssistantTextContentChunk {
    /// "assistant_text_content" — or "assistant_reasoning",
    /// or "assistant_refusal", for the sibling chunks.
    pub r#type: AssistantTextContentChunkType,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub logprobs: Option<Vec<Logprob>>,
    #[serde(flatten)]
    pub inner: TextContent,
}

/// Every chunk's marker enum takes this form: one variant,
/// renamed to the discriminant string.
pub enum AssistantTextContentChunkType {
    #[serde(rename = "assistant_text_content")]
    AssistantTextContent,
}

pub struct Logprob {
    pub token: String,
    pub bytes: Option<Vec<u8>>,
    pub logprob: Decimal,
    pub top_logprobs: Vec<TopLogprob>,
}

pub struct TopLogprob {
    pub token: String,
    pub bytes: Option<Vec<u8>>,
    pub logprob: Option<Decimal>,
}
```

### `assistant_image_content`, `assistant_audio_content`

An image or audio the agent produced — one shape, two discriminants,
no log probabilities.

```rust
pub struct AssistantImageContentChunk {
    /// "assistant_image_content" — or "assistant_audio_content",
    /// flattening AudioContent instead.
    pub r#type: AssistantImageContentChunkType,
    #[serde(flatten)]
    pub inner: ImageContent,
}
```

### `assistant_tool_call`, `tool_response`

A tool call the agent issued, and the answer it received; `id`
correlates the two.

```rust
pub struct AssistantToolCallChunk {
    /// "assistant_tool_call"
    pub r#type: AssistantToolCallChunkType,
    /// Quoted by the answering tool_response chunk.
    pub id: String,
    #[serde(flatten)]
    pub inner: CallToolRequestParams,
}

pub struct ToolResponseChunk {
    /// "tool_response"
    pub r#type: ToolResponseChunkType,
    /// The id of the assistant_tool_call this answers.
    pub id: String,
    #[serde(flatten)]
    pub inner: CallToolResult,
}
```

### `usage`

Token accounting.

```rust
pub struct UsageChunk {
    /// "usage"
    pub r#type: UsageChunkType,
    pub completion_tokens: u64,
    pub prompt_tokens: u64,
    pub total_tokens: u64,
    #[serde(rename = "_meta", default, skip_serializing_if = "Option::is_none")]
    pub meta: Option<MetaObject>,
}
```

### `notification`

A condition the server reports, in its own vocabulary.

```rust
pub struct NotificationChunk {
    /// "notification"
    pub r#type: NotificationChunkType,
    /// Whether the reported condition ends the loop.
    pub is_fatal: bool,
    pub message: serde_json::Value,
    #[serde(rename = "_meta", default, skip_serializing_if = "Option::is_none")]
    pub meta: Option<MetaObject>,
}
```

### `continuation`

The token a subsequent
[request](/endpoints/agentic-loop-run/request/) presents to resume
this loop. Opaque to the client.

```rust
pub struct ContinuationChunk {
    /// "continuation"
    pub r#type: ContinuationChunkType,
    pub continuation: String,
    #[serde(rename = "_meta", default, skip_serializing_if = "Option::is_none")]
    pub meta: Option<MetaObject>,
}
```
