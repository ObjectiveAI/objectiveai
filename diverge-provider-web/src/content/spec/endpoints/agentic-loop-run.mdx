---
title: 'agentic_loop::run'
summary: "Run an agent in a provider-supplied container and stream its chunks; the agent's MCP tool calls travel back to the caller."
order: 1
---

The caller sends the agent's request body; the provider deploys the
matching agent image, relays the loop's chunks down the scope as they
are produced, and serves the agent's own MCP asks — tool calls above
all — out to the caller on channels. A caller that disconnects does
not end the run: the work was already paid for, and the run finishes
whether or not anyone is listening.
