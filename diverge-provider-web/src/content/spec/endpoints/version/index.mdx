A request whose payload is the tag byte `9` alone opens the scope.
The server answers with exactly one response, whose payload is the
revision of this specification the server implements, and then the
response finish.

- **The question carries nothing.** The tag is the whole request; see
  [Request](/endpoints/version/request/).
- **The answer is fixed.** The response is the specification
  revision, a string of the form `MAJOR.MINOR.PATCH`, the same string
  every page of this specification prints as its revision. Nothing
  else is a conforming answer; see
  [Response](/endpoints/version/response/).
- **There is no error.** The scope carries one response and the
  finish. No frame of this endpoint reports a failure.
- **It assumes nothing but frames.** The request and its answer
  depend on no other exchange, so a client that does not yet know
  which revision a server implements learns it here before composing
  any other request.
