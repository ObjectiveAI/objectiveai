The request's payload is one byte:

```text
[9]
```

- **Nothing follows the tag.** The request has no parameters.
- **Bytes after the tag are ignored.** A server reads the tag and
  disregards the remainder of the payload; a request with bytes after
  the tag is not malformed.
- **A payload without a tag is malformed.** An empty payload is not a
  request of any endpoint; the [Endpoints](/endpoints/) layer states
  how a server answers a request it cannot read.
