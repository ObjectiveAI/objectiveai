The server sends exactly one response on the scope, then the response
finish.

```text
[revision: utf8 …]
```

- **The payload is `%%REVISION%%`.** The whole payload is that string,
  UTF-8, running to the end of the frame: no tag, no length. It is the
  revision of this specification, `MAJOR.MINOR.PATCH`, and a server
  that implements this revision answers exactly it. A server sends no
  other string, and not the empty string. A server implementing
  another revision answers that revision's string, as that revision
  defines it.
- **One response, then the finish.** The finish follows the response
  and nothing else does. A finish with no response before it is the
  request not served, as [Endpoints](/endpoints/) states.
- **Malformed.** A payload that is not valid UTF-8 is malformed.
