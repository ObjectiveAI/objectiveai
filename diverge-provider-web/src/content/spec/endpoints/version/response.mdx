The server sends exactly one response on the scope, then the response
finish.

```text
[revision: utf8 …]
```

- **The payload is the revision.** The whole payload is the string,
  UTF-8, running to the end of the frame: no tag, no length. The
  string is the revision of this specification the server implements,
  `MAJOR.MINOR.PATCH` — at this revision, the string printed at the
  top of this page. A server sends no other string, and not the
  empty string.
- **One response, then the finish.** The finish follows the response
  and nothing else does. A finish with no response before it is the
  request not served, as [Endpoints](/endpoints/) states.
- **Malformed.** A payload that is not valid UTF-8 is malformed.
