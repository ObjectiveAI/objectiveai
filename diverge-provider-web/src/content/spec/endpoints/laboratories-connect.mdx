---
title: 'laboratories::connect'
summary: "Join a running laboratory by its id, subject to the runner's authorization, with the same asks a runner has."
order: 4
---

A connector names a laboratory by the id its runner was told and
offers an opaque authorization; the provider relays that to the
runner, whose yes also names the connector. An admitted connector gets
the same live filesystem view and the same asks — files, transfers,
MCP — against a container it does not own: leaving takes nothing with
it, and the laboratory ending takes the connection with it.
