```text
[0][document JSON …]    the image's /DIVERGE.md, parsed
[1]                     the image ships no /DIVERGE.md
[2][error JSON …]       the file could not be read, or is not a document
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server did not serve the
  question.
- **The document.** The byte `0` is followed by exactly one JSON
  object, the document that [Document](/shared/document/#the-document)
  defines, read from the file that
  [Document](/shared/document/#the-file) defines.
- **Missing.** The byte `1` alone states that the image ships no
  `/DIVERGE.md`, or that what the image holds at that path is not a
  regular file. Nothing follows the byte. That is a fact about the
  image and not a failure.
- **The error.** The byte `2` is followed by exactly one JSON value
  in the form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page.
  An error whose `kind` is `info` states that the file is
  [not a document](/shared/document/#not-a-document), or that the
  server could no longer obtain the image the scope held. Any other
  error states that the server could not read the image.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0`, `1` and `2`, and a payload whose bytes after `0` or
  `2` do not parse as the document or as the error are malformed. A
  payload whose first byte is `1` is read by that byte alone; bytes
  after it are not read.
