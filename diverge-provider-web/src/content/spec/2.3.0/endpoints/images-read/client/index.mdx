The client opens each of these channels on the scope, as
[Channels](/frames/channels/) provides. The payload of the channel
request begins with one tag byte designating the channel; the
remainder is the channel's request. Tags `0` and `1` are, byte for
byte, the asks of tags `0` and `1` the server makes of a client on a
[containers::agents::run](/endpoints/containers-agents-run/server/)
or [containers::tools::run](/endpoints/containers-tools-run/server/)
scope — the same tags, the same request bodies, the same answers —
with the client asking and the server answering. Tag `2` carries,
byte for byte, the `prove` ask that [Possession](/shared/possession/#the-ask)
defines, with the client asking and the server answering. Tag `4`
asks for the [document](/shared/document/) of the image of the scope. The server answers
each on its channel as its section states, and answers a channel
request that does not decode by a channel response finish that no
channel response precedes.

| Tag | Channel |
|-----|---------|
| `0` | [oci-manifest](/endpoints/images-read/client/oci-manifest/) |
| `1` | [oci-blob](/endpoints/images-read/client/oci-blob/) |
| `2` | [oci-prove](/endpoints/images-read/client/oci-prove/) |
| `3` | [cancel](/endpoints/images-read/client/cancel/) |
| `4` | [info](/endpoints/images-read/client/info/) |
