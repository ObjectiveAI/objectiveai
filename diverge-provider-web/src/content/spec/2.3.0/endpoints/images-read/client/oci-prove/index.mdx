The client opens this channel to ask the server for the proof that
[Possession](/shared/possession/) defines over the image of the scope,
the image the request of [images::read](/endpoints/images-read/) names.

- **The request.** The tag byte `2` followed by the `prove` ask as
  JSON: the platform, or none, and the nonce.
  [Request](/endpoints/images-read/client/oci-prove/request/) states its form.
- **The response.** Exactly one channel response, the proof, and the
  channel response finish, or a channel response finish that no
  channel response precedes.
  [Response](/endpoints/images-read/client/oci-prove/response/) states the sequence.
- **The proof.** The server computes the proof that
  [Possession](/shared/possession/#the-proof) defines, with the nonce
  of the ask, over the image bytes `D` that
  [Possession](/shared/possession/#the-image-bytes) defines for the
  image of the scope and the `platform` of the ask.
- **The nonce.** The server computes the proof with the 32 bytes the
  ask carries as its nonce, whatever their value.
- **Nothing moves.** The server sends no byte of the image on the
  channel and changes nothing in any Store.
