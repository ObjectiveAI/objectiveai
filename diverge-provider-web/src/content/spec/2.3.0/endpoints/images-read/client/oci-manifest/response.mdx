```text
[media_type_len: u16, big-endian][media_type: utf8 …][manifest bytes …]      at most once
```

- **The sequence.** At most one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server does not answer the digest
  on the scope: the image of the scope does not reach the digest, as
  [images::read](/endpoints/images-read/) states, or the server cannot
  supply its bytes.
- **The frame.** A `u16`, big-endian, the byte length of the media
  type; the media type, UTF-8; the bytes of the manifest, verbatim,
  running to the end of the payload. The bytes are those the digest
  names.
