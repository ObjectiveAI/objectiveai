The client opens this channel to pull a blob of the image of the
scope: a config or a layer of an image manifest the image reaches, by
digest.

- **The request.** The tag byte `1` followed by the digest as JSON.
  [Request](/endpoints/images-read/client/oci-blob/request/) states its form.
- **The response.** The bytes of the blob in zero or more channel
  responses and the channel response finish.
  [Response](/endpoints/images-read/client/oci-blob/response/) states the sequence.
- **What the image reaches.** The server answers only a digest the
  image of the scope reaches, as [images::read](/endpoints/images-read/)
  states. The server answers any other digest with the channel
  response finish and nothing before it.
