The payload of the request is the tag byte followed by exactly one
JSON object, the image, running to the end of the payload:

```text
[20][image JSON …]
```

- **The image.** An object of two members:
  `{"digest":"<algorithm>:<hex>","references":[{"registry":"…","name":"…"}]}`,
  the form the `image` of a
  [containers::tools::run request](/endpoints/containers-tools-run/request/)
  has.
- **`digest`.** The manifest digest of the image, of the form
  `<algorithm>:<hex>`. The digest identifies the image.
- **`references`.** An array of objects, each of two members:
  `registry`, a registry host with no scheme and no path, as
  `docker.io` or `registry.example.com:5000`; and `name`, a
  repository path at that registry with no host and no tag, as
  `library/nginx`. A server obtains a referenced image as
  `<registry>/<name>@<digest>`. The member is absent when the array
  is empty.
- **The references locate.** A reference does not identify the image:
  every registry that serves the bytes the digest names serves the
  same image. The server consults a referenced registry only where the
  registry is in its
  [`images_registries`](/capabilities/#images_registries), and
  ignores a reference that names a registry not in it.
- **No other member.** The request states no source. It carries no
  member that asks the server to look in, or to omit, either source;
  the server answers from the sources that
  [images::read](/endpoints/images-read/) states.
- **One image.** The request names exactly one image. Every channel of
  the scope is an ask about that image, as
  [images::read](/endpoints/images-read/) states.
- **Malformed.** A payload with no byte, a payload whose first byte is
  not `20`, and a payload whose bytes after the tag do not parse as
  the image are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
