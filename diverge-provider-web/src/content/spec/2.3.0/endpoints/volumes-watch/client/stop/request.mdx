The payload of the channel request is empty:

```text
[]
```

- **No parameter.** The channel request carries nothing. The frame
  itself, on a channel of this scope, is the whole of the stop.
- **Bytes in the payload.** A server ignores every byte of a payload
  that is not empty. A channel request with a payload is not
  malformed, and it is the stop.
- **Not malformed.** No payload of a channel request on this scope is
  malformed.
