```text
[connection JSON …]
```

- **No tag.** The server opens one kind of channel on an accept
  scope, so its channel request carries no tag: the payload is the
  connection as JSON, read as [Notation](/endpoints/#notation)
  provides.
- **`connection_id`.** The id the server minted for the connection,
  an integer. The acceptor quotes it, as four bytes big-endian, in
  the channel request of its half.
- **`identity`.** The identity of the connection the connect scope
  was opened on, as the [authorization](/authorization/) established
  it: an object with exactly the members `issuer` and `subject`, each
  a string, the `iss` and the `sub` claims of the token the connector
  presented.
- **`address`.** The peer IP address of that connection, as the
  server observed it.
