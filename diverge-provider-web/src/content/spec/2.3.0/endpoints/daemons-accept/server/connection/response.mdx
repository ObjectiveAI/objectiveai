```text
[message …]    zero or more, one message of the relayed connection each
```

- **The sequence.** Zero or more channel responses, each one message of the relayed connection with no tag in front, in the order the
  acceptor sent them. The channel response finish is the acceptor
  hanging up: the server finishes the connect scope with no error. A
  channel response finish that no channel response precedes, before
  the acceptor has opened its half, states that the acceptor declined
  the connection: the server answers the connect scope with exactly
  one response, the error `{"kind":"denied"}`, and the finish.
- **The message.** Each channel response is exactly one message of
  the relayed connection, verbatim as the acceptor sent it, with no
  tag in front. The first is the acceptor's authorization frame, the
  answer, as [Authorization](/authorization/) states. Every later one
  is one frame of the acceptor's, sealed under the relayed
  connection's keys, as [Sealing](/sealing/) states. The server reads
  no message, and requires no form of one: no channel response is
  malformed.
- **What the server does with it.** The server relays each channel
  response onto the connect scope as one response, the byte `2`
  followed by the frame verbatim.
