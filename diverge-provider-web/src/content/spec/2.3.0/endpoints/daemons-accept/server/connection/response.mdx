```text
[type: u8][scope: u32][channel: u32][payload …]    zero or more, one server frame each
```

- **The sequence.** Zero or more channel responses, each one server
  frame of the daemon protocol with no tag in front, in the order the
  acceptor sent them. The channel response finish is the acceptor
  hanging up: the server finishes the connect scope with no error. A
  channel response finish that no channel response precedes, before
  the acceptor has opened its half, states that the acceptor declined
  the connection: the server answers the connect scope with exactly
  one response, the error `{"kind":"denied"}`, and the finish.
- **The frame.** Each channel response is exactly one server frame of
  the daemon protocol, laid out as [Frames](/frames/) lays out a
  server frame: the type byte `2`, a response; `3`, a response
  finish; `4`, a channel request the acceptor opened; `5`, a channel
  response; `6`, a channel response finish; never `0`. The scope and
  the channel in it are the connector's, and are not read on this
  wire.
- **What the server does with it.** The server relays each channel
  response onto the connect scope as one response, the byte `2`
  followed by the frame verbatim.
