The server sends exactly one response on the scope. After the
identity the scope stays open, and the response finish ends it; after
an error or the already-open response the response finish follows at
once. No frame bearing the
scope follows the finish.

```text
[0][accepting JSON …]    once, the identity, and the scope stays open
[1][error JSON …]        once, and the finish follows
[2]                      once, alone, when an accept is open already, and the finish follows
```

- **The sequence.** Exactly one response precedes the response
  finish. The byte `0` is the identity: the scope stays open, and
  the finish follows the acceptor's cancel or the acceptor's connection
  ending. The byte `1` is an error, and the byte `2` is the refusal
  of an accept already open: the finish follows either, and no
  connection is announced. A response finish that no response
  precedes states that the request was not served, as
  [Endpoints](/endpoints/) provides.
- **The identity.** A payload whose first byte is `0` carries, after
  that byte as JSON, an object with the member `identity`: the
  identity of the connection the scope was opened on, as the
  [authorization](/authorization/) established it. The identity is an
  object with exactly the members `issuer` and `subject`, each a
  string: the `iss` and the `sub` claims of the token the acceptor
  presented. A connector names the acceptor by exactly this object.
- **The error.** A payload whose first byte is `1` carries, after
  that byte, exactly one JSON value in the form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page.
  This revision prescribes nothing about its content.
- **Already open.** A payload that is the byte `2` and nothing else
  states that an accept scope is open already: on the connection, as
  [One open at a time](/endpoints/#one-open-at-a-time) provides, or
  under the identity on any connection, as
  [daemons::accept](/endpoints/daemons-accept/) provides. Bytes after
  it are not read.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0` to `2`, and a payload whose bytes after `0` or `1`
  do not parse as the stated JSON are malformed.
