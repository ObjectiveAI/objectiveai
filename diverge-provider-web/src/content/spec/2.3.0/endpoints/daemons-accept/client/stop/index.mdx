The acceptor ends the scope by opening this channel. The server sends
no frame on the channel; the response finish of the scope is its
answer.

- **The request.** The payload is the tag byte `1` and nothing more.
  [Request](/endpoints/daemons-accept/client/stop/request/) states
  its form.
- **The response.** The server sends nothing on the channel.
  [Response](/endpoints/daemons-accept/client/stop/response/) states
  the sequence.
- **The effect.** When the server receives the channel request, it
  finishes every half of every connection open on the scope, finishes
  every connect scope relayed to it, releases the identity, and sends
  the response finish of the scope. The server reads no further
  channel request on the scope.
