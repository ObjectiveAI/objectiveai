The payload of the request is the tag byte followed by exactly one
JSON object, the image, running to the end of the payload:

```text
[23][image JSON …]
```

- **The image.** An object of two members:
  `{"digest":"<algorithm>:<hex>","references":[{"registry":"…","name":"…"}]}`,
  in the form the request of
  [images::has](/endpoints/images-has/request/) has. `digest` is the
  manifest digest of the image, of the form `<algorithm>:<hex>`, and
  identifies the image. `references` is an array of objects of two
  members, `registry` and `name`, as
  [images::has](/endpoints/images-has/request/) states them, and is
  absent when the array is empty. A reference locates the image and
  does not identify it.
- **One image.** The request names exactly one image. Every channel of
  the scope is an ask about that image, as
  [images::oci](/endpoints/images-oci/) states.
- **Malformed.** A payload with no byte, a payload whose first byte is
  not `23`, and a payload whose bytes after the tag do not parse as
  the image are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.

The request is defined by
`diverge-sdk-rs/src/provider/endpoints/images/oci/client/request/frame.rs`,
read as [Notation](/endpoints/#notation) provides:

```rust include=diverge-sdk-rs/src/provider/endpoints/images/oci/client/request/frame.rs
```

and the image it carries by `diverge-sdk-rs/src/shared/containers/oci/has/request/request.rs`, the
request that [images::has](/endpoints/images-has/) carries:

```rust include=diverge-sdk-rs/src/shared/containers/oci/has/request/request.rs
```
