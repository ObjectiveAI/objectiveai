The server sends on the main stream either no response before the
response finish, or exactly one response, as the first frame of the
main stream, followed by the response finish.

```text
(nothing)      the main stream carries no response: the pull is served
[0]            once, alone: the server cannot supply the image, and serves no channel
[1]            once, alone: the server has neither a Store nor any registry, and serves no channel
```

- **The sequence when served.** Where the server can supply the image
  the request names, it sends no response on the main stream. Every
  answer comes on the channel of the ask it answers. The response
  finish follows the last answer of every channel still open when the
  server receives the client's
  [cancel](/endpoints/images-oci/client/cancel/) or the client's
  connection ends, and no frame follows the finish.
- **The sequence when not served.** Where the server sends a response,
  it sends exactly one, as the first frame of the main stream, and the
  response finish follows it. The server answers no channel, before
  the response or after it.
- **Not found.** A payload that is the byte `0` and nothing else
  states that the server cannot supply the image the request names
  from the sources that [images::oci](/endpoints/images-oci/) states.
  It states no reason and names no source.
- **Unsupported.** A payload that is the byte `1` and nothing else
  states that the server holds out no
  [`images_store`](/capabilities/#images_store) capability and that
  its [`images_registries`](/capabilities/#images_registries) is
  empty, as [Capabilities](/capabilities/) provides.
- **No bytes after the answer.** The server sends nothing after the
  byte `0` or the byte `1`, and a client ignores every byte that
  follows either.
- **Not served.** A response finish that the client did not ask for
  by a cancel, and that no response precedes, states that the server
  will not serve the pull, as [Endpoints](/endpoints/) provides for a
  request not served. The server serves no channel after it.
- **Malformed.** A payload with no byte, and a payload whose first
  byte is neither `0` nor `1`, are malformed.
