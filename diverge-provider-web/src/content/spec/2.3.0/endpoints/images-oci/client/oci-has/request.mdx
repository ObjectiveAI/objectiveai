```text
[2][request JSON …]
```

- **`digest`.** The manifest digest, `<algorithm>:<hex>`.
- **No name.** The ask names no repository. The server's store is
  keyed by digest, and the repository path the server holds the image
  under is the server's to answer.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes.
