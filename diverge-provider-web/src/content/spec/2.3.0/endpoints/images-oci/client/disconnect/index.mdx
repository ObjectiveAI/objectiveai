The client ends the scope by opening this channel. The server sends
no frame on the channel; the response finish of the scope is its
answer.

- **The request.** The payload is the tag byte `3` and nothing more.
  [Request](/endpoints/images-oci/client/disconnect/request/) states its form.
- **The response.** The server sends nothing on the channel.
  [Response](/endpoints/images-oci/client/disconnect/response/) states the sequence.
- **The effect.** When the server receives the channel request, it
  answers every ask still open on the scope, and then sends the
  response finish of the scope. The server reads no further channel
  request on the scope.
- **The one end the client has.** A pull scope does not end on its
  own. A client that is done ends the scope with this, or by ending
  its connection.
