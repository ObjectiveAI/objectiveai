The client opens each of these channels on the scope, as
[Channels](/frames/channels/) provides. The payload of the channel
request begins with one tag byte designating the channel; the
remainder is the channel's request. Tags `0`, `1` and `2` are, byte
for byte, the asks of tags `0`, `1` and `2` the server makes of a
client on a [containers::agents::run](/endpoints/containers-agents-run/server/)
or [containers::tools::run](/endpoints/containers-tools-run/server/)
scope — the same tags, the same request bodies, the same answers —
with the client asking and the server answering. The server answers
each on its channel as its section states, and answers a channel
request that does not decode by a channel response finish that no
channel response precedes.

| Tag | Channel |
|-----|---------|
| `0` | [oci-manifest](/endpoints/images-oci/client/oci-manifest/) |
| `1` | [oci-blob](/endpoints/images-oci/client/oci-blob/) |
| `2` | [oci-has](/endpoints/images-oci/client/oci-has/) |
| `3` | [disconnect](/endpoints/images-oci/client/disconnect/) |
