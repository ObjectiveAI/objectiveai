```text
[1][image]            once: the server holds the image for the client
[0]                    once: it does not
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server does not hold the image
  for the client.
- **The frame.** The byte `0` and nothing after it: the server does
  not hold the image for the client. The byte `1` followed by exactly
  the five bytes of the UTF-8 string `image`: the server holds the
  image the digest names in the client's Store. The server sends no
  other bytes after the byte `1`. A frame whose first byte is
  neither, a frame of the byte `0` followed by anything, a frame of
  the byte `1` followed by nothing, and a frame whose bytes after `1`
  are not UTF-8 are malformed.
- **The label.** The string `image` is a label. It names no
  repository of the server, and the server holds the image under no
  name: the client's Store is keyed by digest.
- **What follows.** A client that was answered `1` may ask for the
  manifest and blobs of the image on
  [oci-manifest](/endpoints/images-oci/client/oci-manifest/) and
  [oci-blob](/endpoints/images-oci/client/oci-blob/) channels.
