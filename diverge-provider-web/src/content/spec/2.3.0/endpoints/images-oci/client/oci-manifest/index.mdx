The client opens this channel to pull a manifest of the image of the
scope: the manifest the request of the scope names or, where that
manifest is an image index, a manifest the index lists.

- **The request.** The tag byte `0` followed by the digest as JSON.
  [Request](/endpoints/images-oci/client/oci-manifest/request/) states its form.
- **The response.** At most one channel response, the media type and
  the manifest verbatim, and the channel response finish.
  [Response](/endpoints/images-oci/client/oci-manifest/response/) states the sequence.
- **What the image reaches.** The server answers only a digest the
  image of the scope reaches, as [images::oci](/endpoints/images-oci/)
  states. The server answers any other digest with the channel
  response finish and nothing before it.
