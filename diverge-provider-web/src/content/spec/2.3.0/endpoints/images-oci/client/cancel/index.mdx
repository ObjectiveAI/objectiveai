The client ends the scope by opening this channel. The server sends
no frame on the channel; the response finish of the scope is its
answer.

- **The request.** The payload is the tag byte `2` and nothing more.
  [Request](/endpoints/images-oci/client/cancel/request/) states its form.
- **The response.** The server sends nothing on the channel.
  [Response](/endpoints/images-oci/client/cancel/response/) states the sequence.
- **The effect.** When the server receives the channel request, it
  answers every ask still open on the scope and sends the response
  finish of the scope after the last of those answers. The server
  reads no further channel request on the scope.
- **The one end the client has.** A pull scope that the server serves
  does not end on its own. A client that is done ends the scope with
  this channel, or by ending its connection.
