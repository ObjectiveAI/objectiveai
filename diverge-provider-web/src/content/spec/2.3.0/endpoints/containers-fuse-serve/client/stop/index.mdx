The client opens this channel to end the FUSE serve. The server serves no
ask opened after the stop, stops the [filesystem::fuse_serve](/container-proxy-endpoints/filesystem-fuse-serve/)
scope it holds on the proxy of the container, answers every ask still
open as the proxy answers it, and sends the response finish on the
scope. The server releases nothing: the container is the runner's.

- **The request.** The tag byte `9` and nothing after it.
  [Request](/endpoints/containers-fuse-serve/client/stop/request/) states its form.
- **The response.** Nothing. [Response](/endpoints/containers-fuse-serve/client/stop/response/)
  states what the server sends instead.
- **Once.** A second stop on one scope changes nothing.
