The server sends exactly one response on the scope, and sends it
before it serves any channel.

```text
[0]                  serving: the proxy serves the directory, and the asks are answered
[1]                  not served: the server does not FUSE serve containers
[2][error JSON …]    not served
```

- **The sequence.** Exactly one response, first. After a response
  whose payload is exactly the one byte `0`, the scope stays open:
  the server sends no other response on the scope, answers every
  channel the client opens as [Client Channels](/endpoints/containers-fuse-serve/client/) states,
  and sends the response finish after the last answer when the client
  stops or the container ends. After a response whose first byte is
  `1` or `2`, the response finish follows the response, and no frame
  follows the finish. A response finish that no response precedes
  states that the request was not served, as [Endpoints](/endpoints/)
  provides.
- **Serving.** The server sends the byte `0` only after the proxy of
  the container has answered `Serving` on the
  [filesystem::fuse_serve](/container-proxy-endpoints/filesystem-fuse-serve/) scope the server
  opened for the request.
- **Unsupported.** A payload that is the byte `1` and nothing else
  states that the server holds out no
  [`containers_fuse_serve`](/capabilities/#containers_fuse_serve)
  capability. The server sends it before it looks up the container,
  opens nothing on any proxy, and serves no channel. A client ignores
  every byte that follows the byte `1`.
- **The error.** A payload whose first byte is `2` carries an error
  after that byte, running to the end of the payload. The error is
  exactly one JSON value, in the form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page.
  An id that names no container the client is running is answered
  with exactly `{"kind":"missing"}`; a directory the proxy refused is
  answered with the error the proxy sent, verbatim. This revision
  prescribes nothing else about its content.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0`, `1` and `2`, a payload whose first byte is `0` and
  that has a byte after it, and a payload whose bytes after `2` are
  not one JSON value are malformed.
