The client opens this channel on the scope, as [Channels](/frames/channels/) provides. The payload of the channel request begins with one tag byte designating the channel; the remainder is the channel's request. The server serves it as its section states, and answers a channel request that does not decode by a channel response finish that no channel response precedes.

| Tag | Channel |
|-----|---------|
| `0` | [stop](/endpoints/volumes-list/client/stop/) |
