The payload of the request is the tag byte followed by the request as
JSON, read as [Notation](/endpoints/#notation) provides:

```text
[2][request JSON …]
```

- **`id`.** The id the response of a run carried. The server resolves
  it among the containers it is running; it means nothing outside the
  server that minted it.
- **`path`.** An array of strings: the components of the directory to
  serve, from the root of the container. An empty array names the
  root of the container. No component is empty, `.` or `..`, or
  contains `/` or NUL; a path with such a component is answered with
  an error, not as malformed.
- **Malformed.** A payload with no byte, a payload whose first byte
  is not `2`, and a payload whose bytes after the tag do not parse as
  the request are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
