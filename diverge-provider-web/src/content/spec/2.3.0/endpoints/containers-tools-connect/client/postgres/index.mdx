A connector has no half of a database connection to open: the
container's connections go to its runner. The server answers every
channel request of this tag on a connect scope by a channel response
finish that no channel response precedes.

- **The request.** The tag byte `4` followed by four bytes.
  [Request](/endpoints/containers-tools-connect/client/postgres/request/) states its form.
- **The response.** No channel response.
  [Response](/endpoints/containers-tools-connect/client/postgres/response/) states it.
