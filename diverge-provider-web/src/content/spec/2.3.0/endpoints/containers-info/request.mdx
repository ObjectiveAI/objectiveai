The payload of the request is the tag byte followed by the request as
JSON, running to the end of the payload:

```text
[3][request JSON …]
```

- **`image`.** An object of two members, in the form a container
  request names its image.
- **`image.digest`.** The manifest digest of the image, of the form
  `<algorithm>:<hex>`. The digest identifies the image.
- **`image.references`.** An array of objects, each of two fields:
  `registry`, a registry host with no scheme and no path, `docker.io`,
  `registry.example.com:5000`; and `name`, a repository path at that
  registry with no host and no tag, `library/nginx`. A server fetches
  a referenced image as `<registry>/<name>@<digest>`. Absent when
  there are none.
- **The references locate.** A reference does not identify the
  image. The server asks a referenced registry only where its own
  policy lists that registry, and ignores a reference naming one it
  does not. A reference whose `name` is not a repository path is
  answered with the error, and the server reads nothing.
- **No other field.** The request states no source, no limit and no
  argument. The server looks in every place it looks for a container
  request, less the client.
- **Malformed.** A payload with no byte, a payload whose first byte
  is not `3`, and a payload whose bytes after the tag do not parse as
  the request are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
