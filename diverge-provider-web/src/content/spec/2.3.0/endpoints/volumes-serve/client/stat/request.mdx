```text
[6][path …]
```

- **The form.** The bytes after the tag are exactly the bytes after
  the tag of the [FUSE stat](/container-proxy-endpoints/fuse-mount/server/stat/request/) ask on a
  mount scope, and mean the same; that page states every field. The
  path is UTF-8, `/`-separated, with no leading `/`; empty is the
  root of the volume.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
