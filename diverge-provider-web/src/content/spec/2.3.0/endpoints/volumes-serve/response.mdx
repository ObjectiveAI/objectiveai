The server sends exactly one response on the scope, and sends it
before it serves any channel.

```text
[0]              serving: the volume is held, and the asks are answered
[1][error JSON …]  not served
```

- **The sequence.** Exactly one response, first. After a response
  whose payload is exactly the one byte `0`, the scope stays open:
  the server sends no other response on the scope, answers every
  channel the client opens as [Client Channels](/endpoints/volumes-serve/client/) states,
  and sends the response finish after the last answer when the client
  stops. After a response whose first byte is `1`, the response
  finish follows the response, and no frame follows the finish. A
  response finish that no response precedes states that the request
  was not served, as [Endpoints](/endpoints/) provides.
- **The error.** A payload whose first byte is `1` carries an error
  after that byte, running to the end of the payload. The error is
  exactly one JSON value, in the form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page.
  This revision prescribes nothing about its content.
- **Malformed.** A payload with no byte, a payload whose first byte
  is neither `0` nor `1`, a payload whose first byte is `0` and that
  has a byte after it, and a payload whose bytes after `1` are not one
  JSON value are malformed.
