The client ends the scope by opening this channel. The server sends
no frame on the channel; the response finish of the scope is its
answer.

- **The request.** The payload is the tag byte `0` and nothing more.
  [Request](/endpoints/containers-tools-list-for/client/stop/request/) states its form.
- **The response.** The server sends nothing on the channel.
  [Response](/endpoints/containers-tools-list-for/client/stop/response/) states the sequence.
- **The effect.** When the server receives the channel request, it
  ends the listing: it lets go of every ask it has open on the
  runners' scopes and sends the response finish of the scope. No
  container is stopped, and no runner is told. The server reads no
  further channel request on the scope.
- **The one end the lister has.** A listing does not end because the
  identity runs nothing. A lister that has read what it wanted —
  the byte `2`, for a lister that wanted the listing once — ends the
  scope with this, or by ending its connection.
