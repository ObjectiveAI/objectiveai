summary: 'Responses of the byte 0 and one container as JSON, added, and of the byte 1 and one container as JSON, removed, as the runners allow and the runs begin and end; the byte 2, once, when the listing is whole; or the byte 3 and an error, last; and the response finish.'
order: 2

```text
[0][container JSON …]   per container added, as its runner allows
[1][container JSON …]   per container removed, after it was added
[2]                     once, when every runner asked at the opening has answered or gone
[3][error JSON …]       at most once, last
```

- **The sequence.** Zero or more responses of the byte `0` followed
  by one container as JSON, in the order the runners' answers arrive;
  exactly one response of the byte `2` and nothing else, once every
  runner asked at the opening has answered or gone; then zero or more
  responses of the byte `0` or the byte `1`, each followed by one
  container as JSON, as the identity's tool containers begin and end
  and their runners allow; the response finish follows the last of
  them, when the lister stops or the lister's connection ends. Or: the
  responses sent so far, exactly one response of the byte `3`
  followed by an error as JSON, and the response finish. No response
  follows the error. A response of the byte `0` may precede the byte
  `2`, since a runner answers in its own time, and may follow it,
  since the identity may start a container.
- **`id`.** The id the container's run was answered with: the string
  a [containers::tools::connect](/endpoints/containers-tools-connect/)
  request names.
- **Added.** A response of the byte `0` states that the container's
  runner allowed the lister to see it. The server sends it exactly
  once per container per scope.
- **Removed.** A response of the byte `1` states that the container's
  run ended. The server sends it only for a container it sent as
  added on this scope, and exactly once for it.
- **Whole.** A payload that is the byte `2` and nothing else states
  that every container running under the identity when the scope
  opened has been sent as added or will not be. A lister that wants
  the listing once reads to this byte and
  [stops](/endpoints/containers-tools-list-for/client/stop/). The
  byte states nothing about containers started after the scope
  opened. A payload whose first byte is `2` is read by that byte
  alone; bytes after it are not read.
- **A finish with nothing before it.** The request was not served,
  as [Endpoints](/endpoints/) provides, or the lister stopped before
  the server had sent anything. The server does not say which.
- **The error.** An error states that the server did not ask, and
  that nothing was determined about the containers the lister was
  not sent. Responses sent before the error were sent as their
  runners allowed.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0`, `1`, `2` and `3`, and a payload whose first byte is
  `0`, `1` or `3` and whose bytes after it do not parse as the
  variant are malformed.
