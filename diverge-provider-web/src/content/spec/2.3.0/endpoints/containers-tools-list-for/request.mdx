The payload of the request is the tag byte followed by the request as
JSON, read as [Notation](/endpoints/#notation) provides:

```text
[3][identity JSON …]
```

- **`kind`.** The string `unbrokered`. It is the one value this
  revision defines, and a payload whose `kind` is any other string
  does not parse. A value for a brokered identity is reserved for a
  later revision.
- **`identity`.** The identity whose containers the lister asks for:
  the string under which a connection of that identity was
  authorized, as [Authorization](/authorization/) provides. The server
  compares it and does not read it. An identity that runs no tool
  container is not an error.
- **Malformed.** A payload with no byte, a payload whose first byte
  is not `3`, and a payload whose bytes after the tag do not parse as
  the request are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
