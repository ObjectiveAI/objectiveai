The server sends exactly one response on the scope. The response
finish follows the response, and no frame follows the finish.

```text
[discover JSON …]
```

```json
{"identities":[{"issuer":"https://issuer.example","subject":"daemon"}]}
```

- **The payload.** The payload of the response is one JSON object,
  read as [Notation](/endpoints/#notation) provides, running to the
  end of the frame. No tag precedes it and no length prefixes it.
  The object has exactly one member, `identities`, and the server
  sends no other member.
- **`identities`.** An array of identities. Each identity is an
  object with exactly the members `issuer` and `subject`, each a
  string: the `iss` and `sub` claims of the token under which the
  identity's connection was authorized.
- **Every discoverable identity.** The array holds the identity of
  every connection open to the server whose client sent the discover
  flag `1`, as [discover](/endpoints/discover/) provides, and no other
  identity.
- **Once each.** No identity appears in the array more than once.
- **In order.** The array is sorted by `issuer`, and identities of the
  same `issuer` by `subject`, each compared byte by byte as UTF-8.
- **None.** A server with no discoverable identity connected sends
  the array empty, as `{"identities":[]}`.
- **The sequence.** Exactly one response precedes the response
  finish, and nothing follows the finish. A response finish that no
  response precedes states that the request was not served, as
  [Endpoints](/endpoints/) provides.
- **Malformed.** A payload that is not valid UTF-8, a payload that is
  not exactly one JSON object, an object with no `identities` member,
  and an `identities` member that is not an array of identities are
  malformed.
