```text
[0][identity, postcard …]   per identity added
[1][identity, postcard …]   per identity removed, after it was added
[2]                         once, when the listing is whole
```

- **The sequence.** Zero or more responses of the byte `0` followed
  by one identity, one per identity in the listing when the scope
  opened; exactly one response of the byte `2` and nothing else; then
  zero or more responses of the byte `0` or `1`, each followed by one
  identity, as discoverable identities connect and disconnect. The
  response finish follows the last of them, when the client stops or
  the client's connection ends. The server sends no response of the
  byte `1` before the byte `2`.
- **The identity.** A payload whose first byte is `0` or `1` carries
  one identity after that byte, running to the end of the payload.
  The identity is the pair defined below, encoded as the postcard
  reading of [Notation](/endpoints/#notation) provides: its `issuer`
  as a varint byte length followed by that many bytes of UTF-8,
  followed by `subject` as a varint byte length followed by that many
  bytes of UTF-8.
- **`issuer`.** The `iss` claim of the token under which the
  identity's connection was authorized, as
  [Authorization](/authorization/) provides.
- **`subject`.** The `sub` claim of that token.
- **Added.** A response of the byte `0` states that the identity is
  in the listing. The server sends it exactly once while the identity
  is listed: for every identity listed when the scope opened, before
  the byte `2`; for an identity listed after, when its connection has
  completed its authorization.
- **Removed.** A response of the byte `1` states that the identity is
  no longer in the listing, and carries the identity as the server
  sent it as added. The server sends it only for an identity it has
  sent as added on this scope and not since as removed, and exactly
  once for it.
- **Whole.** A payload that is the byte `2` and nothing else states
  that every identity in the listing when the scope opened has been
  sent as added. A client that wants the listing once reads to this
  byte and [stops](/endpoints/discover/client/stop/). A payload whose
  first byte is `2` is read by that byte alone; bytes after it are not
  read.
- **Order.** The order of the identities is not prescribed. A client
  reads nothing into the position of an identity.
- **A finish with nothing before it.** The request was not served, as
  [Endpoints](/endpoints/) provides, or the client stopped before the
  server had sent anything. The server does not say which.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0` to `2`, and a payload whose bytes after `0` or `1` do
  not decode as one identity are malformed.
