The server sends exactly one response on the scope. The response
finish follows the response, and no frame follows the finish.

```text
[0][tree, postcard …]
[1][error JSON …]
```

- **The sequence.** Exactly one response precedes the response
  finish, and nothing follows the finish. A response finish that no
  response precedes states that the request was not served, as
  [Endpoints](/endpoints/) provides.
- **The tree.** A payload whose first byte is `0` carries the tree
  after that byte, running to the end of the payload: a varint count
  followed by that many nodes, in the encoding the postcard reading
  of [Notation](/endpoints/#notation) provides. A node is one of the
  three variants the
  [filetree](/endpoints/containers-agents-run/client/filetree/response/)
  channel defines, `File`, `Directory` or `Symlink`, in the form that
  page states, with these determinations. Every `Directory` has
  `changes` `0`: nothing watches the volume, and no change is sent. A
  `Symlink` is the link itself, never followed, and its `path` is the
  target of the link as components relative to the root of the
  volume. `created_at` and `modified_at` are what the volume records,
  absent where it records none. The count `0` is an empty directory,
  and the payload is exactly the one byte `0`.
- **Paths.** Every `name` is the name of a node in its directory. The
  directory the request named has no node of its own: the tree
  carries its entries.
- **The error.** A payload whose first byte is `1` carries an error
  after that byte, running to the end of the payload. The error is
  exactly one JSON value, in the form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page.
  This revision prescribes nothing about its content.
- **Malformed.** A payload with no byte, a payload whose first byte
  is neither `0` nor `1`, a payload whose bytes after `0` do not
  decode as the tree, and a payload whose bytes after `1` are not one
  JSON value are malformed.
