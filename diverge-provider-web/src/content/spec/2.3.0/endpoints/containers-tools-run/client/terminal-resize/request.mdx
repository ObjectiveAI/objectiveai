The payload of the channel request is the tag byte followed by the
request, read as [Notation](/endpoints/#notation) provides:

```text
[19][resize JSON …]
```

- **`id`.** The id that [terminal-open](/endpoints/containers-tools-run/client/terminal-open/) answered.
- **`cols`, `rows`.** The terminal's new size, as the proxy's
  [terminal request](/container-proxy-endpoints/terminal/request/) states them.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.

The channel request is defined by `diverge-sdk-rs/src/provider/endpoints/containers/tools/run/client/channel_request/frame.rs`:

```rust include=diverge-sdk-rs/src/provider/endpoints/containers/tools/run/client/channel_request/frame.rs
```

and by `diverge-sdk-rs/src/shared/containers/terminal/session.rs`:

```rust include=diverge-sdk-rs/src/shared/containers/terminal/session.rs
```
