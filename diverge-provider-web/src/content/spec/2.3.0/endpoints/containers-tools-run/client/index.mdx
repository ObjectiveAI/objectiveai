The client opens each of these channels on the scope, as [Channels](/frames/channels/) provides. The payload of the channel request begins with one tag byte designating the channel; the remainder is the channel's request. The server serves each as its section states, and answers a channel request that does not decode by a channel response finish that no channel response precedes.

| Tag | Channel |
|-----|---------|
| `0` | [stop](/endpoints/containers-tools-run/client/stop/) |
| `1` | [filetree](/endpoints/containers-tools-run/client/filetree/) |
| `2` | [read](/endpoints/containers-tools-run/client/read/) |
| `3` | [write](/endpoints/containers-tools-run/client/write/) |
| `4` | [postgres](/endpoints/containers-tools-run/client/postgres/) |
| `5` | [mcp-list-tools](/endpoints/containers-tools-run/client/mcp-list-tools/) |
| `6` | [mcp-list-resources](/endpoints/containers-tools-run/client/mcp-list-resources/) |
| `7` | [mcp-call-tool](/endpoints/containers-tools-run/client/mcp-call-tool/) |
| `8` | [mcp-read-resource](/endpoints/containers-tools-run/client/mcp-read-resource/) |
| `9` | [mcp-notifications](/endpoints/containers-tools-run/client/mcp-notifications/) |
