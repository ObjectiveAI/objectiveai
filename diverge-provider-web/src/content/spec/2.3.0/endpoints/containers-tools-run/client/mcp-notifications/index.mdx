The client opens this channel to receive the notifications of the MCP
server of the container. The server opens a notifications channel
on the begin scope of the container's proxy and relays every
notification the proxy sends.

- **The request.** The tag byte `9` and nothing more.
  [Request](/endpoints/containers-tools-run/client/mcp-notifications/request/) states its
  form.
- **The response.** One channel response per notification, an error
  last when the proxy sent one, and the channel response finish when
  the proxy finishes. [Response](/endpoints/containers-tools-run/client/mcp-notifications/response/)
  states the sequence.
- **From the opening on.** The server relays no notification that
  the proxy sent before this channel's own was opened.
