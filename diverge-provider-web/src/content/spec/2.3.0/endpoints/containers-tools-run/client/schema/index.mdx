The client opens this channel to learn the schema of the arguments
the container was made with. The server opens a schema channel on
the begin scope of the container's proxy and relays its answer.

- **The request.** The tag byte `6` and nothing more.
  [Request](/endpoints/containers-tools-run/client/schema/request/) states its form.
- **The response.** Exactly one channel response, the schema or an
  error, and the channel response finish.
  [Response](/endpoints/containers-tools-run/client/schema/response/) states the
  sequence.
- **A courtesy.** An image that states no schema is answered by the
  error. A schema is not a requirement on the image.
