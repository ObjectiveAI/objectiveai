```text
[10]{"session": …, "params": …}
```

- **The session.** The member `session` is the caller whose MCP
  session the exchange belongs to, as the daemon attests it: the
  object the key `diverge.network` holds on a request's `_meta`, an
  agent or a client. Two callers are one session when their agents
  have one template and one index, or their clients one issuer and one
  subject. The server passes the session on to the container's proxy,
  which opens one MCP session to the container's server per session
  named, on the first channel request that names it, by
  an `initialize` that carries the caller under `_meta`, and sends the
  exchange on that session.
- **The params.** The member `params` holds the params of the MCP method `tools/call`, as JSON,
  read as [Notation](/endpoints/#notation) provides, relayed to the
  proxy verbatim.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
