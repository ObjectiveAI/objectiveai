The payload of the request is the tag byte followed by the container
as JSON, read as [Notation](/endpoints/#notation) provides.

```text
[1][container JSON …]
```

- **`image`.** An object of two fields: `{"name":…,"digest":…}`.
  `name` is a repository path without a host; `digest` is
  `<algorithm>:<hex>`, the manifest digest, which identifies the
  image. The request names no source: where the server obtains the
  image is the server's own.
- **`memory`, `disk`.** Limits in bytes: the memory the container may
  use, and the bytes the container may write to its own filesystem.
  Neither governs a mount.
- **`volume_mounts`.** Ordered; the server applies them in order.
  `host_name` is a `name` in the client's listing; `host_relative_path`
  and `container_path` are components. An empty `container_path`
  names the root, which the server refuses. `persist` is present and
  is `true` or `false`: `true`, every change the container makes to
  the volume is in the volume when the container ends; `false`, the
  volume is as it was before the run when the container ends. The
  container sees the volume's content as of its start either way.
- **`fuse_file_mounts`, `fuse_directory_mounts`.** Each names a path
  and an `id` the client chose. Every one is mounted before the id
  is sent. A directory mount is a tree the client serves: every entry
  beneath its root is created, written, renamed and removed by the
  container, each change one ask to the client, and the root alone
  cannot be removed or renamed. A file mount is one file, overwritten
  in place and never removed, renamed or replaced. Whether a change
  is allowed is the client's answer to the ask; the server enforces
  nothing.
- **Paths.** No component of any mount's path is empty, `.` or `..`.
  No two mounts have one path. No mount lies inside another mount: a
  volume mount inside a FUSE mount no more than a FUSE mount inside a
  volume mount. No mount's path is the root.
- **Ids.** No two FUSE mounts, on either list, have one `id`.

- **Malformed.** A payload with no byte, a payload whose first byte
  is not `1`, and a payload whose bytes after the tag do not
  parse as the request are malformed. [Endpoints](/endpoints/) states
  how a server answers a request it cannot read.
