```text
[22][id_len: u16, big-endian][id …][from_len: u16, big-endian][from …][to …]
```

- **The ask.** The bytes after the tag are the ask as the proxy's
  [`/fuse/rename/{channel}`](/proxy/fuse/rename/) page defines them,
  relayed verbatim: the id of the mount, and the path of the entry
  relative to the root of the mount.

The channel request is defined by `diverge-provider-sdk/src/endpoints/containers/tools/run/server/channel_request/frame.rs`:

```rust include=diverge-provider-sdk/src/endpoints/containers/tools/run/server/channel_request/frame.rs
```

and by `diverge-provider-sdk/src/shared/containers/fuse/rename/request/request.rs`:

```rust include=diverge-provider-sdk/src/shared/containers/fuse/rename/request/request.rs
```
