```text
[bytes …]      zero or more, the blob
```

- **The sequence.** Zero or more channel responses, each a piece of
  the blob verbatim with no tag and no header, in order; the pieces
  concatenated are the blob. The channel response finish follows the
  last. A channel response finish that no channel response precedes
  states that the client does not hold the digest, and the run
  fails.
