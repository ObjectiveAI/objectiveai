```text
[proof: 32 bytes]      exactly once: the proof
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the client does not hold the image,
  and the check fails.
- **The frame.** Exactly 32 bytes, the proof, with no tag and no
  header, as [Possession](/shared/possession/#the-answer) defines. A
  payload of any other length is malformed, and the check fails.
- **The comparison.** The server compares the proof with the value it
  computes over the bytes it holds, as
  [Possession](/shared/possession/#the-comparison) states.
