The server opens this channel when the image of the request is of
kind `client` and its registry does not hold a blob that the pull
requires: a config or a layer.

- **When.** Between the request and the deploy.
- **The request.** The tag byte `1` followed by the digest as JSON.
  [Request](/endpoints/containers-tools-run/server/oci-blob/request/) states its form.
- **The response.** The bytes of the blob in zero or more channel
  responses and the channel response finish.
  [Response](/endpoints/containers-tools-run/server/oci-blob/response/) states the
  sequence.
- **The image.** The server runs only the image the digest names. A
  blob that ends short, and bytes that are not those the digest
  names, are the run's error. How the server holds, verifies or
  streams the bytes, and how it answers a range the runtime asks
  for, are not prescribed.
