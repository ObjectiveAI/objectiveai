The server opens this channel when the container's proxy opens the
corresponding MCP channel on the begin scope. The params are relayed
verbatim; the client's one answer is relayed back.

- **The request.** The tag byte `14` followed by the params as JSON.
  [Request](/endpoints/containers-tools-run/server/mcp-read-resource/request/) states its form.
- **The response.** Exactly one channel response, a result or an
  MCP error, and the channel response finish.
  [Response](/endpoints/containers-tools-run/server/mcp-read-resource/response/) states the sequence.
- **The conduit.** The server relays the one channel response onto
  the proxy's channel as one channel response and finishes it. The
  server does not read the params or the answer, and does not send
  the ask twice.
