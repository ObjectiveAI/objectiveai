```text
[25][id_len: u16, big-endian][id …][size: u64, big-endian][path …]
```

- **The ask.** The bytes after the tag are the id of the mount, which
  the server adds, and the ask as the
  [Container Proxy Endpoints](/container-proxy-endpoints/) layer
  defines it, relayed verbatim: the path of the entry relative to the
  root of the mount, and what the ask carries.

The channel request is defined by `diverge-sdk-rs/src/provider/endpoints/containers/tools/run/server/channel_request/frame.rs`:
