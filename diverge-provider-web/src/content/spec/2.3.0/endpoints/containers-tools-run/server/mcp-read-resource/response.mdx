```text
[0][result JSON …]    the result
[1][error JSON …]     the MCP error
```

- **The sequence.** Exactly one channel response followed by the
  channel response finish. The server relays either variant to the
  container as the answer.
- **A finish with nothing.** A channel response finish that no
  channel response precedes states that the client did not serve the
  ask. The server relays that to the proxy as a channel response
  finish that no channel response precedes, and does not ask again.
