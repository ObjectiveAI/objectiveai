- **`id`.** A string: the id of the run the container is registered
  for, as the server minted it and as the response carries it after
  the channel has ended and the values have been fed. The server has
  entered the container among those it runs when it sends this, so a
  [containers::fuse_serve](/endpoints/containers-fuse-serve/) naming the id is
  answered while the channel is open.
- **`dependencies`.** Absent. A tool container declares no
  dependencies, and the server carries none on a tools-run scope.
- **`secrets`.** A JSON object whose every member is a secret's name,
  as the container's template declares it, to the mode the program
  takes it in, the string `fixed` or `rotating`, in the order the
  program declared them. A `fixed` secret is read: the client hands
  the container one value at every activation and takes nothing
  back. A `rotating` secret is held: the client locks one value to
  the container at every activation, and the container hands it
  back, as the program leaves it, on the `Inactive` that ends the
  container's activity. A name the template does not declare is the
  registration's error, in the client's words. A name the template
  declares and the declaration omits is a secret the program does
  not take, and is never fed. The server relays the declaration as
  the proxy sent it and reads none of it. Absent when empty.
- **`permissions`.** An array of grants, in the order the program
  declared them; absent when empty. Each grant is an object of
  exactly one member named for a kind, whose value is a bare array of
  making actions, an object of `actions` and `within`, or an object
  of `actions`, `within` and `tags`. A `within` is the string `any`
  or an object of `all_tags` and `any_tags`, and names nothing; over
  agents alone, a `within` may also be the string `attached`, the
  agents attached to the tool, or the string `never_active`, the
  agents that have never run. The server relays the array as the
  proxy sent it and reads none of it.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
