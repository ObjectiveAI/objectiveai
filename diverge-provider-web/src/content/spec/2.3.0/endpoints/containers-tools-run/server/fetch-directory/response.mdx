```text
[path_len: u32, big-endian][path JSON …][bytes …]      zero or more
```

- **The sequence.** Zero or more channel responses, each one file or
  one piece of one file, in any order of files. Each carries a
  `u32`, big-endian, the byte length of the path; the path, a JSON
  array of strings, the components of the file relative to the
  directory; and the bytes, verbatim, running to the end of the
  payload. Consecutive channel responses with one path are one file,
  their bytes appended in order; a channel response with a new path
  begins a new file. A file of zero bytes is one channel response
  with no bytes. The channel response finish follows the last. A
  channel response finish that no channel response precedes states
  that the client does not hold the identity, and the run fails.
- **A frame that does not decode.** The server skips it, and the
  verification against the identity fails.
