[4][request JSON …]

- **`tools`.** An array of tools, in the order the program declared
  them. Each is an object of five members, and a sixth that may be
  absent: `name`, a string, unique
  in the array, the client's label for the tool container — the
  container never finds a server by it, and calls tools by whatever
  names the client's merged list shows; `image`, an object of `name` and `digest` as the
  [request](/endpoints/containers-tools-run/request/) of a tools run
  names one; `memory` and `disk`, limits in bytes as that request
  states them; `arguments`, any JSON value, the `arguments` of that
  request; and `instructions`, a string, absent when the program
  states none. The mounts of a tools run are not here: the client
  chooses them, and `instructions` is where a tool says in words what
  it needs of them — a mount at some path, a volume of some shape —
  and anything else the client needs to know to deploy it. The server
  relays `instructions` and does not read it.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
