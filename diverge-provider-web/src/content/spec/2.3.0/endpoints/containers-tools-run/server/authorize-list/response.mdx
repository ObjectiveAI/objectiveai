```text
[0]      denied
[1]      authorized
```

- **The sequence.** Exactly one channel response of exactly one
  byte, followed by the channel response finish. The byte `1` sends
  the container on the list scope. The byte `0`, any other byte, and
  a channel response finish that no channel response precedes keep
  it unsent: the server sends nothing on the list scope for this
  container, and the lister cannot tell the three apart.
