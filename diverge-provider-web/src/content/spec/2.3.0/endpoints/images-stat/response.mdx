The server sends exactly one response on the scope. The response
finish follows the response, and no frame follows the finish.

```text
[0][stat, postcard …]    the image, examined
[1]                      not examined: the server keeps no client image
[2][error JSON …]        not examined
```

- **The sequence.** Exactly one response precedes the response
  finish, and nothing follows the finish. A response finish that no
  response precedes states that the request was not served, as
  [Endpoints](/endpoints/) provides.
- **The stat.** A payload whose first byte is `0` carries the stat
  after that byte, running to the end of the payload. The stat is the
  `Stat` defined below, encoded as the postcard reading of
  [Notation](/endpoints/#notation) provides: the image as the
  [images::list response](/endpoints/images-list/response/) defines
  it — `name`, `digest`, `bytes`, `created` — followed by
  `containerfile` as a varint byte length followed by that many bytes
  of UTF-8.
- **`name`, `digest`, `bytes`, `created`.** The image as the client's
  listing reports it. The four values equal those the listing reports
  for the image at the time of the response.
- **`containerfile`.** The Containerfile the image was built from,
  UTF-8: the `containerfile` of the client's
  [images::build](/endpoints/images-build/) request, verbatim.
- **Unsupported.** A payload that is the byte `1` and nothing else
  states that the server holds out no
  [`images_store`](/capabilities/#images_store) capability and keeps
  no client image, as [Capabilities](/capabilities/) provides. It is
  the only response of the scope, sent before anything is looked up;
  bytes after it are not read.
- **The error.** A payload whose first byte is `2` carries an error
  after that byte, running to the end of the payload. The error is
  exactly one JSON value, in the form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page.
  This revision prescribes nothing about its content.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0`, `1` and `2`, a payload whose bytes after `0` do not
  decode as the stat, and a payload whose bytes after `2` are not one
  JSON value are malformed.
