A client opens the scope with a request whose payload is the tag byte
`16` followed by the digest of an image. The server sends exactly one
response, which is the image examined, the word that the server
keeps no Store, or an error. The response finish follows the
response, and no frame follows the finish.

- **The request.** The request carries the digest of one image.
  [Request](/endpoints/images-stat/request/) states its form.
- **The image named.** The client names an image by the `digest` its
  [images::list](/endpoints/images-list/) listing gave it. The server
  resolves the digest against the Store of the identity under which
  the connection was authorized, as [Authorization](/authorization/)
  provides. A digest of no image in the client's Store is answered
  with an error, whether or not the digest is that of an image in
  another identity's Store.
- **The answer.** The answer carries the four fields the listing
  reports for the image, and one more: the Containerfile it was built
  from, which is absent for an image the client pushed.
  [Response](/endpoints/images-stat/response/) states its form.
- **The error.** An error states that the image was not examined, and
  that nothing was determined about it. An image absent from the
  client's listing is answered with an error.
- **No Store.** A server that holds out no
  [`images_store`](/capabilities/#images_store) capability keeps no
  Store and answers every request of this endpoint with exactly one
  response, the byte `1` alone, and the response finish, before
  anything is looked up. Every other requirement of this page holds
  for a server that holds the capability out.
