The payload of the request is the tag byte followed by the request in
the postcard wire format, as the postcard reading of
[Notation](/endpoints/#notation) provides:

```text
[5][name_len: varint][name: utf8 …][path_count: varint][component …]
```

- **`name`.** The name of the volume, UTF-8, preceded by its byte
  length as a varint. It is the `name` of a volume in the client's
  [volumes::list](/endpoints/volumes-list/) listing.
- **`path`.** The components of the path, as a varint count followed
  by that many strings, each a varint byte length followed by that
  many bytes of UTF-8. The count is at least `1`; no
  component is empty, `.` or `..`, or contains `/` or NUL.
- **Bytes after the request.** A server ignores every byte that
  follows the last component. A request whose payload extends past the
  request is not malformed.
- **Malformed.** A payload with no byte, a payload whose first byte
  is not `5`, and a payload whose bytes after the tag do not decode
  as the request are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
