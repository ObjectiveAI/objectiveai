The payload of the request is the tag byte followed by exactly one
JSON object, the prove request, running to the end of the payload, read
as [Notation](/endpoints/#notation) provides:

```text
[21][prove request JSON …]
```

- **The prove request.** The object is the `prove` ask that
  [Possession](/shared/possession/#the-ask) defines:
  `{"image":<image>,"platform":"<algorithm>:<hex>","nonce":"<64 hex>"}`,
  with `platform` absent where no platform is named.
- **`image`.** The image, an object of two members, `digest` and
  `references`, in the form the request of
  [images::has](/endpoints/images-has/request/) has. `digest` is the
  manifest digest of the image, of the form `<algorithm>:<hex>`, and
  identifies the image. `references` locates it, and is absent when
  the array is empty.
- **`platform`.** Absent, or the digest of one manifest that the image
  index the `digest` names lists, of the form `<algorithm>:<hex>`. It
  has the meaning the `platform` of the
  [`prove` ask](/shared/possession/#the-ask) has.
- **`nonce`.** The nonce, a JSON string of exactly 64 hexadecimal
  characters, as the [`prove` ask](/shared/possession/#the-ask)
  states.
- **Malformed.** A payload with no byte, a payload whose first byte is
  not `21`, and a payload whose bytes after the tag do not parse as
  the prove request — among them a payload whose `nonce` is not
  exactly 64 hexadecimal characters — are malformed.
  [Endpoints](/endpoints/) states how a server answers a request it
  cannot read.
