The server sends exactly one response on the scope. The response
finish follows the response, and no frame follows the finish.

```text
[0][proof: 32 bytes]   the proof
[1]                    no proof: no such image is in the client's Store
[2]                    no proof: the server keeps no Store
[3][error JSON …]      no proof
```

- **The sequence.** Exactly one response precedes the response
  finish, and nothing follows the finish. A response finish that no
  response precedes states that the request was not served, as
  [Endpoints](/endpoints/) provides.
- **Hash.** A payload whose first byte is `0` carries exactly 32
  bytes after that byte, the proof that
  [Possession](/shared/possession/#the-proof) defines, computed over
  the bytes of the image the server holds for the client's Store, with
  the nonce of the request.
- **Not found.** A payload whose first byte is `1` states that no
  image of the digest is in the client's Store, or that the request
  breaks the requirement on `platform` that
  [Possession](/shared/possession/#the-image-bytes) states. The server sends nothing after the byte `1`, and a client
  ignores every byte that follows it.
- **Unsupported.** A payload that is the byte `2` and nothing else
  states that the server holds out no
  [`images_store`](/capabilities/#images_store) capability and keeps
  no Store, as [Capabilities](/capabilities/) provides. It is the only
  response of the scope, sent before anything is looked up; bytes
  after it are not read.
- **The error.** A payload whose first byte is `3` carries an error
  after that byte, running to the end of the payload. The error is
  exactly one JSON value, in the form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page.
  This revision prescribes nothing about its content.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0`, `1`, `2` and `3`, a payload whose first byte is `0`
  and whose bytes after it are not exactly 32, and a payload whose
  bytes after `3` are not one JSON value are malformed.
