The server opens this channel when the container's proxy opens a
command channel on the begin scope. The bytes of the command are
relayed verbatim.

- **The request.** The tag byte `5` followed by the bytes of the
  command. [Request](/endpoints/containers-agents-run/server/command/request/) states its
  form.
- **The response.** One channel response per item, an error last
  when the client sends one, and the channel response finish.
  [Response](/endpoints/containers-agents-run/server/command/response/) states the
  sequence.
- **The conduit.** The server relays each channel response onto the
  proxy's channel as one channel response, in order, and finishes it
  when the channel finishes. The server does not read the command or
  an item, and does not send the command twice.
