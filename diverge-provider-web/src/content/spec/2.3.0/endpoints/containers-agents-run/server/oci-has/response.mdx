```text
[1][name: utf8 …]      once: the client holds the image, under that repository path
[0]                    once: it does not
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the client does not hold the image.
- **The frame.** The byte `0` and nothing after it: the client does
  not hold the image. The byte `1` followed by one or more bytes of
  UTF-8: the client holds the image the digest names, and the bytes
  are the repository path it holds it under, with no host and no tag.
  A frame whose first byte is neither, a frame of the byte `0`
  followed by anything, a frame of the byte `1` followed by nothing,
  and a frame whose bytes after `1` are not UTF-8 are malformed.
- **What follows.** A client that answered `1` may be asked for the
  manifest and blobs of the image on
  [oci-manifest](/endpoints/containers-agents-run/server/oci-manifest/) and
  [oci-blob](/endpoints/containers-agents-run/server/oci-blob/) channels, and is asked the
  nonce check on exactly one
  [oci-prove](/endpoints/containers-agents-run/server/oci-prove/) channel. A server treats a
  path that is not a repository path as the answer `0`. A client that
  answered `0` is not asked.
- **The path is a label.** The server uses the repository path the
  client answered only as a label in the reference of its own
  retrieval of the image for this run. The server does not store the
  path, and does not read it as the identifier of an image, of a
  client or of anything else.
