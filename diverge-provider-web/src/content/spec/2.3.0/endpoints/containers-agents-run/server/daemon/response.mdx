```text
[0][type: u8][scope: u32][channel: u32][payload …]    one server frame of the daemon protocol
[1][error JSON …]                                    last, the frame could not be served
```

- **The sequence.** Zero or more channel responses whose first byte
  is `0`, each one server frame of the daemon protocol as
  [Frames](/frames/) lays out a server frame — the type byte `2`, a
  response; `3`, a response finish; `4`, a channel request the
  daemon opened; `5`, a channel response; `6`, a channel response
  finish; never `0` — in the order the daemon sent them. An error,
  when the client sends one, is the last channel response: the frame
  could not be served at all, and nothing of its scope or channel
  follows. The channel response finish follows the last channel
  response.
- **A finish with nothing.** A channel response finish that no
  channel response precedes states that the client did not serve the
  frame. The server relays that to the proxy as a channel response finish that no channel response precedes, and does not ask again.
