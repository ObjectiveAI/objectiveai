title: 'Response'
summary: 'The sequence of channel responses that answers the channel, what ends it, and what a finish with nothing before it means.'
order: 2
draft: false
---

```text
[type: u8][scope: u32][channel: u32][payload …]    zero or more, one server frame each
```

- **The sequence.** Zero or more channel responses, each one server
  frame of the daemon protocol with no tag in front, in the order the
  daemon sent them. The channel response finish is the daemon closing
  the connection: the server closes the program's socket. A channel
  response finish that no channel response precedes states that the
  client declined the connection, and the server closes the program's
  socket at once.
- **The frame.** Each channel response is exactly one server frame of
  the daemon protocol, laid out as [Frames](/frames/) lays out a
  server frame: the type byte `2`, a response; `3`, a response
  finish; `4`, a channel request the daemon opened; `5`, a channel
  response; `6`, a channel response finish; never `0`. The scope and
  the channel in it are the program's, and are not read on this wire.
