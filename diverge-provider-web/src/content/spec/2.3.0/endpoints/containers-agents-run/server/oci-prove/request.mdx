- **The ask.** The `prove` ask that [Possession](/shared/possession/#the-ask)
  defines: `nonce`, the 32 bytes of a nonce the server generated for
  this check alone, as 64 lowercase hexadecimal characters; `image`,
  the image the request of the run names, its `digest` and its
  `references` verbatim; and `platform`, absent where the manifest
  `image.digest` names is not an image index, and otherwise the digest
  of the manifest of the platform the server obtained.

