summary: 'Tag 2: the server asks the client whether it holds an image, by name and digest; the client answers with exactly one channel response, the byte 1 or the byte 0, and the channel response finish; a finish that no response precedes states that the client does not hold it.'

The server opens this channel when it would obtain the image of the
request from the client, before it asks for anything of the image.

- **When.** Between the request and the deploy.
- **The request.** The tag byte `2` followed by the name and the
  digest as JSON. [Request](/endpoints/containers-agents-run/server/oci-has/request/)
  states its form.
- **The response.** Exactly one channel response, one byte, and the
  channel response finish. [Response](/endpoints/containers-agents-run/server/oci-has/response/)
  states the sequence.
- **Whether to ask.** The server asks only when it would obtain the
  image from the client. A server that obtains the image from a
  source of its own does not open this channel, and a client is not
  told where the image came from.
