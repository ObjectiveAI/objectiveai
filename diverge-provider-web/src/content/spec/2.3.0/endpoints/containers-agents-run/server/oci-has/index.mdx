summary: 'Tag 2: the server asks the client whether it holds the image of the run, naming it by digest and by references; the client answers with exactly one channel response, the byte 0, or the byte 1 followed by a repository path, and the channel response finish; a finish that no response precedes states that the client does not hold it.'

---

The server opens this channel when it would obtain the image of the
request from the client, before it asks for anything of the image.

- **When.** Between the request and the deploy.
- **The request.** The tag byte `2` followed by the image of the run as JSON. [Request](/endpoints/containers-agents-run/server/oci-has/request/)
  states its form.
- **The response.** Exactly one channel response, the byte `0`, or
  the byte `1` followed by the repository path the client holds the
  image under, and the channel response finish. [Response](/endpoints/containers-agents-run/server/oci-has/response/)
  states the sequence.
- **Whether to ask.** The server asks only when it consults the
  client, in the order that [Image sources](/endpoints/#image-sources)
  states: the image is not in the client's Store, and no registry the
  server consults serves it. A server that obtains the image from
  another source does not open this channel.
