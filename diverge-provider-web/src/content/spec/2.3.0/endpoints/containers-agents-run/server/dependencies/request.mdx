```text
[3][request JSON …]
```

- **`id`.** A string: the id of the run the dependencies are deployed
  for, as the server minted it and as the response carries it after
  the channel has ended. The server has entered the container among
  those it runs when it sends this, so a
  [containers::serve](/endpoints/containers-serve/) naming the id is
  answered while the channel is open.
- **`dependencies`.** An array of dependency tool templates, in the
  order the program declared them. Each is an object of six members,
  and three that may be absent: `name`, a string, unique in the
  array, the client's label for the tool container — the container
  never finds a server by it, and calls tools by whatever names the
  client's merged list shows; `image`, an object of `name` and
  `digest` as the [request](/endpoints/containers-tools-run/request/)
  of a tools run names one; `memory` and `disk`, limits in bytes as
  that request states them; `arguments`, any JSON value, the
  `arguments` of that request; `database`, the string
  `per_agent_instance` or `per_agent_template`, which database scope
  the client gives the tool — one of the tool's own under the agent
  the dependency is deployed for, or one every tool of this
  dependency under every agent made from the same agent template
  shares; `fuse_file_mounts` and `fuse_directory_mounts`, arrays of
  mounts, each an object of `agent_path` and `tool_path`, both arrays
  of path components, a file or a directory of the agent container
  the client serves live at a path of the tool container, absent when
  empty; and `permissions`, an array of grants in the forms
  `shared::permission` defines — each one object with one member
  named for a kind, whose value is a bare array of making actions, an
  object of `actions` and `within`, or an object of `actions`,
  `within` and `tags`, where `within` is the string `any` or an
  object of `all_tags` and `any_tags` and names nothing — absent when
  empty. The volumes of a tools run are not here: the client chooses
  them. The server relays every member and reads none.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
