```text
[3][request JSON …]
```

- **`id`.** A string: the id of the run the dependencies are deployed
  for, as the server minted it and as the response carries it after
  the channel has ended. The server has entered the container among
  those it runs when it sends this, so a
  [containers::serve](/endpoints/containers-serve/) naming the id is
  answered while the channel is open.
- **`dependencies`.** An array of dependency tool templates, in the
  order the program declared them. Each is an object of five members,
  the members of its kind, and one that may be absent: `image`, an
  object of `digest` and `references` as the
  [request](/endpoints/containers-tools-run/request/) of a tools run
  names one; `memory` and `disk`, limits in bytes as that request
  states them; `arguments`, any JSON value, the `arguments` of that
  request; `type`, the string `transient` or `service`, which kind
  of dependency it is, with that kind's own members flat beside it;
  and `permissions`, an array of grants in the forms
  `shared::permission` defines — each one object with one member
  named for a kind, whose value is a bare array of making actions, an
  object of `actions` and `within`, or an object of `actions`,
  `within` and `tags`, where `within` is the string `any` or an
  object of `all_tags` and `any_tags` and names nothing, and, over
  agents alone, may be the string `self`, the agents the dependency
  is a dependency of — absent when empty. The volumes of a tools run
  are not here: the client chooses them. The server relays every
  member and reads none.
- **A transient tool's members.** `fuse_file_mounts` and
  `fuse_directory_mounts`, arrays of mounts, each an object of
  `agent_path` and `tool_path`, both arrays of path components, a
  file or a directory of the agent container the client serves live
  at a path of the tool container, each absent when empty. A
  transient tool's database scope is the agent's it is deployed for,
  and the template says so by its kind alone.
- **A service's members.** `scope`, the string `instance`,
  `template` or `global`: how far the service is shared,
  and its database scope with it — one service and one scope per
  agent that declares it, one per agent template whose agents
  declare it, or one for every agent that declares it, from whatever
  template. A service names no mount.
- **The id.** A template has no name. The client names a dependency
  by the template's id: the lowercase hexadecimal SHA-256 of the
  template as compact JSON with absent members omitted, the image's
  `references` absent too, and the keys of every object sorted
  bytewise at every depth, the `arguments` and every object inside
  them included. One image under different names is one template. Two templates with one id are
  one dependency, and an array that holds one id twice is refused by
  the client as its error. The container calls the tool's tools by
  whatever names the client's merged list shows.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
