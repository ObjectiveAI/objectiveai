```text
[2][image JSON …]
```

- **The image.** Exactly one JSON object, the `image` of the request
  of the run, its `digest` and its `references` verbatim, in the form
  the request of [images::read](/endpoints/images-read/request/) has:
  `{"digest":"<algorithm>:<hex>","references":[{"registry":"…","name":"…"}]}`,
  with `references` absent when the array is empty. The ask carries
  the same argument that [images::read](/endpoints/images-read/) takes.
- **No name.** The ask names no repository path under which the
  client holds the image. `digest` identifies the image; a reference
  locates it at a registry. The repository path the client holds the
  image under is the client's to answer.
