```text
[bytes …]      zero or more, what the database says
```

- **The sequence.** Zero or more channel responses, each the bytes
  the database wrote, verbatim, with no tag and no header, in order;
  a message of the PostgreSQL wire protocol may span several channel
  responses and several may share one. The channel response finish
  is the database connection closed: the server closes the
  container's socket. A channel response finish that no channel
  response precedes states that the client declined to dial, and the
  server closes the container's socket at once.
