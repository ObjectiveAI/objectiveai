```text
[0]      denied
[1]      authorized
```

- **The sequence.** Exactly one channel response of exactly one
  byte, followed by the channel response finish. The byte `1` opens
  the connect scope. The byte `0`, any other byte, and a channel
  response finish that no channel response precedes refuse it: the
  server answers the connector with the error `{"kind":"denied"}`.
