```text
[0]                  one or more messages waited under the key, and are withdrawn
[1]                  nothing waited under the key
[2][error JSON …]    the state of the queue could not be determined
```

- **The sequence.** Exactly one channel response, relayed as the
  proxy sent it, followed by the channel response finish. A channel
  response finish that no channel response precedes states that the
  proxy did not serve the request.
