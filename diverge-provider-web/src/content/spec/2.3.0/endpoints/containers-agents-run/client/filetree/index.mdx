The client opens this channel to watch the filesystem of the
container. The server opens a tree scope on the container's proxy
and relays what the proxy sends.

- **The request.** The payload is the tag byte `1` and nothing more.
  [Request](/endpoints/containers-agents-run/client/filetree/request/) states its form.
- **The response.** A snapshot, one channel response per change, and
  the channel response finish when the scope ends.
  [Response](/endpoints/containers-agents-run/client/filetree/response/) states the
  sequence.
- **What the tree leaves out.** The server names, in the request it
  sends to the proxy, the path of every mount of the container:
  every volume mount, every identity mount, and every FUSE mount. The
  tree the client receives contains none of them and reports no
  change under them.
- **Not before the mounts.** The server does not open a tree scope
  before the last FUSE mount of the container is complete. A
  filetree channel opened earlier waits.
- **Every channel is whole.** Each filetree channel is its own tree
  scope on the proxy, beginning with a snapshot. Two filetree
  channels are two scopes.
- **Stopped with the scope.** When this scope ends, the server stops
  the tree scope it opened for the channel.
