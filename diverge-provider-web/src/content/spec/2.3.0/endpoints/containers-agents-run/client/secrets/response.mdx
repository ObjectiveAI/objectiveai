draft: false

```text
[0]                  fed: the program holds the values
[1][error JSON …]    not fed: the program refused the values
```

- **The sequence.** Exactly one channel response, relayed as the
  proxy sent it, followed by the channel response finish. A channel
  response finish that no channel response precedes states that the
  proxy did not serve the feed.
- **Fed.** The byte `0` states that the container's program holds the
  values: the proxy delivers the next message to it. Nothing follows
  the byte.
- **The error.** The byte `1` states that the program refused the
  values; the bytes after it are exactly one JSON value in the form
  defined on the [volumes::list response](/endpoints/volumes-list/response/)
  page, the program's own words through the proxy. The program holds
  no values, and the proxy delivers nothing to it until a later feed
  is answered `Fed`.
