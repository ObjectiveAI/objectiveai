```text
[0][head JSON …]      first: the response's head
[1][bytes …]          a piece of the response's body
[2][error JSON …]     the request was not served, or the body broke off
```

Each channel response is a response of the proxy's
[frontend](/container-proxy-endpoints/frontend/response/) scope, relayed as it
is, or an error of the server's own.

- **The sequence.** Exactly one response whose first byte is `0`,
  followed by zero or more responses whose first byte is `1`, followed
  by the channel response finish. A response whose first byte is `2` may follow the
  responses whose first byte is `1`; when it does, it is the last
  response. Alternatively, exactly one response whose first byte is
  `2`, followed by the channel response finish.
- **The head.** After the byte `0`, exactly one JSON object of two
  members. `status` is an integer from `0` to `65535`: the status code
  of the program's response. `headers` is an array of two-element
  arrays of strings, each a header name and its value, in the order
  of the program's response. A value that is not valid UTF-8 is
  carried with each invalid sequence replaced by the character
  `U+FFFD`.
- **The body.** After the byte `1`, the bytes of one piece of the
  response's body, verbatim, running to the end of the payload. A
  piece carries at most 2097152 bytes. The pieces, concatenated in
  order, are the response's body.
- **The error.** After the byte `2`, exactly one JSON value in the form
  defined on the [volumes::list response](/endpoints/volumes-list/response/) page. Preceded by no response,
  it states that the request was not served. Preceded by the head, it
  states that the response's body ended before its end.
- **The pace.** The server sends each channel response only while it holds room on
  the channel, as [Credits](/frames/credits/) provides.
- **A finish with nothing.** A channel response finish that no
  channel response precedes states that the request was stopped
  before the program answered it, or that the container stopped.
