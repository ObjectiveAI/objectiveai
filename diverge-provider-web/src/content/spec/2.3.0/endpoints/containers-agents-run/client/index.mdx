The client opens each of these channels on the scope, as [Channels](/frames/channels/) provides. The payload of the channel request begins with one tag byte designating the channel; the remainder is the channel's request. The server serves each as its section states, and answers a channel request that does not decode by a channel response finish that no channel response precedes.

| Tag | Channel |
|-----|---------|
| `0` | [cancel](/endpoints/containers-agents-run/client/cancel/) |
| `1` | [filetree](/endpoints/containers-agents-run/client/filetree/) |
| `2` | [read](/endpoints/containers-agents-run/client/read/) |
| `3` | [write](/endpoints/containers-agents-run/client/write/) |
| `4` | [transfer](/endpoints/containers-agents-run/client/transfer/) |
| `5` | [postgres](/endpoints/containers-agents-run/client/postgres/) |
| `6` | [info](/endpoints/containers-agents-run/client/info/) |
| `7` | [enqueue](/endpoints/containers-agents-run/client/enqueue/) |
| `8` | [dequeue](/endpoints/containers-agents-run/client/dequeue/) |
| `9` | [fuse-mount](/endpoints/containers-agents-run/client/fuse-mount/) |
| `10` | [secrets](/endpoints/containers-agents-run/client/secrets/) |
| `11` | [exec](/endpoints/containers-agents-run/client/exec/) |
| `12` | [terminal-open](/endpoints/containers-agents-run/client/terminal-open/) |
| `13` | [terminal-attach](/endpoints/containers-agents-run/client/terminal-attach/) |
| `14` | [terminal-stdin](/endpoints/containers-agents-run/client/terminal-stdin/) |
| `15` | [terminal-resize](/endpoints/containers-agents-run/client/terminal-resize/) |
| `16` | [terminal-close](/endpoints/containers-agents-run/client/terminal-close/) |
| `17` | [frontend](/endpoints/containers-agents-run/client/frontend/) |
