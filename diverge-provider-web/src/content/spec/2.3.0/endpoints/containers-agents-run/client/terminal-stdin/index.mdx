The client opens this channel to write to a held terminal's input.
The server writes the bytes through the proxy's
[stdin](/container-proxy-endpoints/terminal/client/stdin/) channel and
answers once they are written.

- **The order.** The client opens the next terminal-stdin channel for
  a terminal only after the server finished the last one. The server
  writes the bytes of one channel whole.

- **The request.** [Request](/endpoints/containers-agents-run/client/terminal-stdin/request/) states its form.
- **The response.** [Response](/endpoints/containers-agents-run/client/terminal-stdin/response/) states the sequence.
- **The run ends.** When the run scope ends, the server kills the
  shell of every terminal it holds on it.
