The client opens this channel to withdraw every message waiting in
the agent's queue under a key: the key an
[enqueue](/endpoints/containers-agents-run/client/enqueue/) carried. A message under
another key stays where it is, and a message the agent has taken
stays taken. The server opens a dequeue channel on the begin scope
of the container's proxy with the key and relays its answer.

- **The request.** The tag byte `8` followed by the key as JSON.
  [Request](/endpoints/containers-agents-run/client/dequeue/request/) states its form.
- **The response.** Exactly one channel response and the channel
  response finish. [Response](/endpoints/containers-agents-run/client/dequeue/response/)
  states the sequence.
- **The messages withdrawn.** Each message withdrawn is answered on
  its own [enqueue](/endpoints/containers-agents-run/client/enqueue/) channel with the byte
  `1`, as the proxy answers it.
