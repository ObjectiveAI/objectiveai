The client opens this channel to learn the schema of the agent value
the container was made with. The server opens an agent-schema
channel on the begin scope of the container's proxy and relays its
answer.

- **The request.** The tag byte `6` and nothing more.
  [Request](/endpoints/containers-agents-run/client/agent-schema/request/) states its form.
- **The response.** Exactly one channel response, the schema or an
  error, and the channel response finish.
  [Response](/endpoints/containers-agents-run/client/agent-schema/response/) states the
  sequence.
