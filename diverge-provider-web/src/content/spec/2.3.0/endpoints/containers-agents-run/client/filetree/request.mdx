The payload of the channel request is exactly one byte:

```text
[1]
```

- **No parameter.** The channel request carries nothing after the
  tag. A server ignores every byte that follows the tag.

The channel request is defined by `diverge-sdk-rs/src/provider/endpoints/containers/agents/run/client/channel_request/frame.rs`:
