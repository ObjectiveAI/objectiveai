```text
[0]                  delivered: the agent's program has every message of the batch
[2][error JSON …]    the container refused the batch, or no loop could start on it
```

- **The sequence.** Exactly one channel response, relayed as the
  proxy sent it, followed by the channel response finish. A channel
  response finish that no channel response precedes states that the
  proxy did not serve the batch.
- **One fate.** The channel response is the fate of every message of
  the batch.
- **Delivered.** The byte `0` states that the program of the agent
  holds every message of the batch: the loop the batch started took
  it, or the program accepted it into its own queue while a loop ran,
  and takes it at its next seam. The byte `1` is not sent.
- **A loop ending.** A loop that ends with the batch still waiting
  does not lose it: the batch starts the next loop. The byte `2`
  states that the container refused the batch's content, at the
  start of a loop or at its delivery, or that a loop the batch was
  to start did not start.
