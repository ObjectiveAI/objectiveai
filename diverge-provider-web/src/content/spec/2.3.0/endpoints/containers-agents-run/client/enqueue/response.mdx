```text
[0]                  delivered: the loop took the message
[1]                  dequeued: the message was withdrawn first
[2][error JSON …]    the container refused the message, or no loop could start on it
```

- **The sequence.** Exactly one channel response, relayed as the
  proxy sent it, followed by the channel response finish. A channel
  response finish that no channel response precedes states that the
  proxy did not serve the message.
- **A loop ending.** A loop that ends with the message still waiting
  does not lose it: the message starts the next loop. The byte `2`
  states that the container refused the message's content, at the
  start of a loop or at its delivery, or that a loop the message was
  to start did not start.
