```text
[0][document JSON …]    the image's /DIVERGE.md, parsed
[1]                     the image ships no /DIVERGE.md
[2][error JSON …]       the proxy could not say
```

- **The sequence.** Exactly one channel response, relayed as the
  proxy sent it, followed by the channel response finish. A channel
  response finish that no channel response precedes states that the
  proxy did not serve the question.
- **The document.** The byte `0` is followed by exactly one JSON
  object of at least three and at most six members. `name` is a string, the image's own name,
  as the image states it. `schema` is the JSON Schema of the
  container's `arguments`, as the image states it, and is a JSON
  object. `body` is a string: the markdown text beneath the
  frontmatter in the image's `/DIVERGE.md`, verbatim. `frontend` is present only with the value
  `true`, and states that the image's program serves a frontend, as the
  [frontend](/container-proxy-endpoints/frontend/) endpoint provides; its absence states
  that the program serves none. `chat` is present only with an object as its value,
  and states how an agent's program chats: the object has exactly one
  member, `prompt_modalities`. `structured_decisions` is present only
  with an object as its value, and states how an agent's program makes
  structured decisions: the object has exactly three members,
  `prompt_modalities`, `instruction_modalities` and `choice_modalities`. Each of those four
  members is an object of exactly three members, `image`, `audio` and
  `file`, each a boolean. The absence of `chat` states that the
  program does not chat, and the absence of `structured_decisions`
  states that the program makes no structured decision. The server reads
  no member.
- **Missing.** The byte `1` states that the image ships no
  `/DIVERGE.md`. Nothing follows the byte. That is a fact about the
  image and not a failure.
- **The error.** The byte `2` states that the proxy could not answer
  with the document: the file could not be read, or is not a
  document. The bytes after it are exactly one JSON value in the
  form defined on the [volumes::list response](/endpoints/volumes-list/response/) page.
