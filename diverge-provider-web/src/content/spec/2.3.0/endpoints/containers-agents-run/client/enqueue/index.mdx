The client opens this channel to send a message to the agent. A
message sent while no loop runs starts one, as its prompt; a message
sent while one runs is placed in its queue. The server opens an
enqueue channel on the begin scope of the container's proxy with the
message and relays the fate the proxy answers. What the agent says in
reply is the main stream of the scope, as
[Response](/endpoints/containers-agents-run/response/) states.

- **The request.** The tag byte `7` followed by the message as JSON.
  [Request](/endpoints/containers-agents-run/client/enqueue/request/) states its form.
- **The response.** Exactly one channel response, sent when the fate
  of the message is known, however long that takes, and the channel
  response finish. [Response](/endpoints/containers-agents-run/client/enqueue/response/)
  states the sequence.
