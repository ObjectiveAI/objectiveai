draft: false

```text
[0][bytes …]         a piece of the file
[1][error JSON …]    the content was not supplied
```

- **The sequence.** Zero or more channel responses whose first byte
  is `0`, each a piece of the file in order, followed by the channel
  response finish; or the channel responses sent so far, exactly one
  channel response whose first byte is `1`, and the channel response
  finish.
- **The piece.** After the byte `0`, the bytes of the piece,
  verbatim, running to the end of the payload. Each piece is at most
  `CHUNK_SIZE` bytes, `2 * 1024 * 1024`, the constant
  `diverge-provider-sdk-rs/src/lib.rs` defines; the pieces concatenated are the file, and
  the server measures none.
- **The error.** After the byte `1`, exactly one JSON value, in the
  form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page. A
  channel that ends in the error is a write abandoned: the server
  discards what it wrote, leaves the destination as it was, and
  answers the scope with the error.
- **A finish with nothing.** A channel response finish that no
  channel response precedes is a file of zero bytes.
