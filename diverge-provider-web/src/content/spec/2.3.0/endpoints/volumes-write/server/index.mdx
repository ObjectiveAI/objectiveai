The server opens each of these channels on the scope, as
[Channels](/frames/channels/) provides, when its section states. A
write defines one channel, and its channel request carries no tag:
the payload is empty. The client answers on the channel; what the
server does with the answer, its section states.

| Tag | Channel |
|-----|---------|
| — | [content](/endpoints/volumes-write/server/content/) |
