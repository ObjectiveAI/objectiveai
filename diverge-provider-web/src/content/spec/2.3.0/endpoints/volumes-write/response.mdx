The server sends exactly one response on the scope. The response
finish follows the response, and no frame follows the finish.

```text
[0]                  written: the file is at the path
[1][error JSON …]    not written, and nothing partial is
```

- **The sequence.** Exactly one response precedes the response
  finish, and nothing follows the finish. The response is sent only
  once the content channel has finished, or the write has failed. A
  response finish that no response precedes states that the request
  was not served, as [Endpoints](/endpoints/) provides.
- **Written.** A payload whose first byte is `0` states that the file
  is at the path, whole. The server sends nothing after the byte `0`,
  and a client ignores every byte that follows it.
- **The error.** A payload whose first byte is `1` carries an error
  after that byte, running to the end of the payload. The error is
  exactly one JSON value, in the form defined on the
  [volumes::list response](/endpoints/volumes-list/response/) page.
  This revision prescribes nothing about its content. The error
  states that the file is not at the path as a result of the request,
  that nothing partial is, and that the destination is as it was
  before the request.
- **Malformed.** A payload with no byte, a payload whose first byte
  is neither `0` nor `1`, and a payload whose bytes after `1` are not
  one JSON value are malformed.
