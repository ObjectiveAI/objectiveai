The request's payload is the tag byte, then the request as JSON,
running to the end of the payload:

```text
[8][request JSON …]
```

- **`name`.** The repository path, with no registry host:
  `library/nginx`, `myorg/myimage`.
- **`digest`.** The manifest digest, `<algorithm>:<hex>`, which
  identifies the image.
- **No registry.** The request names no registry. Any registry that
  serves the bytes the digest names serves the image; where the
  server obtains it is not the client's to say.
- **Malformed.** A payload with no tag, a tag other than `8`, or JSON
  after the tag that does not parse as the request is malformed, and
  the [Endpoints](/endpoints/) layer states how a server answers a
  request it cannot read.
