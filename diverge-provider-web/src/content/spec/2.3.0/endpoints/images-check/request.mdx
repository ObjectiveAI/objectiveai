The payload of the request is the tag byte followed by the request as
JSON, running to the end of the payload:

```text
[11][request JSON …]
```

- **`name`.** The repository path of the image, without a registry
  host: `library/nginx`, `myorg/myimage`.
- **`digest`.** The manifest digest of the image, of the form
  `<algorithm>:<hex>`. The digest identifies the image.
- **No registry.** The request names no registry. Every registry
  that serves the bytes the digest names serves the same image, and
  the source from which the server obtains the image is not the
  client's to state.
- **Malformed.** A payload with no byte, a payload whose first byte
  is not `11`, and a payload whose bytes after the tag do not parse as
  the request are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
