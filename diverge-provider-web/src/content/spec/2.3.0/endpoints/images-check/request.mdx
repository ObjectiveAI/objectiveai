The payload of the request is the tag byte followed by the request as
JSON, running to the end of the payload:

```text
[14][request JSON …]
```

- **`digest`.** The manifest digest of the image, of the form
  `<algorithm>:<hex>`. The digest identifies the image.
- **`references`.** An array of objects, each of two fields:
  `registry`, a registry host with no scheme and no path, `docker.io`,
  `registry.example.com:5000`; and `name`, a repository path at that
  registry with no host and no tag, `library/nginx`. A server fetches
  a referenced image as `<registry>/<name>@<digest>`. Absent when
  there are none.
- **The references locate.** A reference does not identify the
  image: every registry that serves the bytes the digest names serves
  the same image. The server asks a referenced registry only where
  its own policy lists that registry, and ignores a reference naming
  one it does not. A reference whose `name` is not a repository path
  is answered with the error.
- **`client`.** A boolean: whether the server is to look among the
  images the client built on it. Absent is `false`.
- **`registries`.** A boolean: whether the server is to ask the
  referenced registries its policy lists. Absent is `false`.
- **No other field.** There is no field that asks the server to look
  among the images it holds on its own account; the server does not
  look among them.
- **At least one.** A request in which neither `client` nor
  `registries` is `true` is answered with the byte `2` alone, and
  the server looks nowhere.
- **Malformed.** A payload with no byte, a payload whose first byte
  is not `14`, and a payload whose bytes after the tag do not parse as
  the request are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
