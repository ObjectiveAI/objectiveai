The server sends exactly one response on the scope. The response
finish follows the response, and no frame follows the finish.

```text
[0][answer JSON …]
[1][error JSON …]
[2]
```

- **The sequence.** Exactly one response precedes the response
  finish, and nothing follows the finish. A response finish that no
  response precedes states that the request was not served, as
  [Endpoints](/endpoints/) provides.
- **The answer.** A payload whose first byte is `0` carries the
  answer as JSON after that byte. The answer is exactly one of two
  objects: `{"type":"available"}` or `{"type":"unavailable"}`. The
  available answer states that at least one source the request asked
  for has the image, at the time of the answer, for a container
  request naming the requested digest: the client's own images, built
  on the server by [images::build](/endpoints/images-build/) and no
  other client's, where `client` was asked; the images the server
  holds on its own account, where `server` was asked; a referenced
  registry the server's policy lists, where `registries` was asked.
  It reserves nothing, and a later container request naming the
  image may fail. The unavailable answer states that no source asked
  has it; a container request naming the image may still succeed
  where the client holds the image, or where a source not asked has
  it. It states no reason and names no source: an image the server cannot obtain and
  an image the server could obtain and will not serve to this client
  receive the same answer.
- **The error.** A payload whose first byte is `1` carries an error
  as JSON after that byte. The error states that the server did not
  answer the question and that nothing was determined about the
  image. An error is not an unavailable answer.
- **No source.** A payload that is the byte `2` and nothing else
  states that the request asked for none of the three sources, that
  the server looked nowhere, and that nothing is determined about
  the image. A payload whose first byte is `2` is read by that byte
  alone; bytes after it are not read.
- **Malformed.** A payload with no byte, a payload whose first byte
  is none of `0`, `1` and `2`, and a payload whose bytes after `0` or
  `1` do not parse as the answer or as the error are malformed.
