The payload of the request is exactly one byte:

```text
[8]
```

- **No parameter.** The request carries nothing after the tag. The
  tag is the whole request.
- **Bytes after the tag.** A server ignores every byte that follows
  the tag. A request whose payload extends past the tag is not
  malformed.
- **Malformed.** A payload with no byte is not a request of any
  endpoint. [Endpoints](/endpoints/) states how a server answers a
  request it cannot read.
