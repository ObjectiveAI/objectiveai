The client opens this channel to end the FUSE serve. The server serves no
ask opened after the cancel, answers every ask still open, sends the
response finish on the scope, and gives the volume back.

- **The request.** The tag byte `9` and nothing after it.
  [Request](/endpoints/volumes-fuse-serve/client/cancel/request/) states its form.
- **The response.** Nothing. [Response](/endpoints/volumes-fuse-serve/client/cancel/response/)
  states what the server sends instead.
- **Once.** A second cancel on one scope changes nothing.
