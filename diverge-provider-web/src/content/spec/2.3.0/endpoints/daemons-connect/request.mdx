The payload of the request is the tag byte followed by the request as
JSON, read as [Notation](/endpoints/#notation) provides:

```text
[23][connect JSON …]
```

- **`daemon`.** The identity an acceptor is known by on this server:
  the object the server answered that acceptor's
  [accept](/endpoints/daemons-accept/response/), with exactly the
  members `issuer` and `subject`, each a string. The server compares
  both members with those of every identity under which an accept
  scope is open and does not otherwise read them.
- **Malformed.** A payload with no byte, a payload whose first byte
  is not `23`, and a payload whose bytes after the tag do not parse
  as the request are malformed. [Endpoints](/endpoints/) states how a
  server answers a request it cannot read.
