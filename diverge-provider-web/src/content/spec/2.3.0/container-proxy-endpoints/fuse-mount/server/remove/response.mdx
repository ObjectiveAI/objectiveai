```text
[0]             ok
[1][message …]  an error, UTF-8
[2]             ephemeral: the storage keeps nothing written into it
```

- **The sequence.** Exactly one channel response, ok, ephemeral, or an error, followed
  by the channel response finish.
- **The message.** The bytes after the error byte are UTF-8, not JSON.
- **Ephemeral.** The byte `2` states that the storage behind the
  mount keeps nothing written into it. The change is refused, and the
  server reports the operation to the program as a read-only
  filesystem.
- **A finish with nothing.** A channel response finish that no
  channel response precedes states that the client did not serve the
  ask. The server does not ask again.
