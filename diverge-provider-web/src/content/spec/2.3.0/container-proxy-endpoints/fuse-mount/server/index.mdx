The server opens each of these channels on the scope, as
[Channels](/frames/channels/) provides, when its section states. The payload of the channel request begins with one tag byte designating the ask; the remainder is the ask, which names no mount: the scope is the mount.
The client answers on the channel; what the server does with the
answer, its section states.

| Tag | Channel |
|-----|---------|
| `0` | [read](/container-proxy-endpoints/fuse-mount/server/read/) |
| `1` | [write](/container-proxy-endpoints/fuse-mount/server/write/) |
| `2` | [list](/container-proxy-endpoints/fuse-mount/server/list/) |
| `3` | [remove](/container-proxy-endpoints/fuse-mount/server/remove/) |
| `4` | [rename](/container-proxy-endpoints/fuse-mount/server/rename/) |
| `5` | [mkdir](/container-proxy-endpoints/fuse-mount/server/mkdir/) |
| `6` | [stat](/container-proxy-endpoints/fuse-mount/server/stat/) |
