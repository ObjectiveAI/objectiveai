The server opens this channel when a program in the container performs
the operation on the mount. The ask names the entry by its path
within the mount, and names no mount: the scope is the mount.

- **The request.** The tag byte `0` followed by the ask.
  [Request](/container-proxy-endpoints/fuse-mount/server/read/request/) states its form.
- **The response.** Exactly one channel response and the channel
  response finish. [Response](/container-proxy-endpoints/fuse-mount/server/read/response/) states the
  sequence.
- **The meaning.** What the ask means, and what its answer means,
  [FUSE read](/endpoints/containers-agents-run/server/fuse-read/) states; the client relays the ask
  to its client with the mount's id in front of it.
- **No repetition.** The server sends the ask exactly once. A channel
  that ends without a finish, and a channel response finish that no
  channel response precedes, are reported to the program as the
  operation failed.
