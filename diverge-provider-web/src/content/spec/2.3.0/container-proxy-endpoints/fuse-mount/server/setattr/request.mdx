```text
[8][attrs: 29 bytes][path …]
```

- **The path.** UTF-8, `/`-separated, with no leading `/`; empty is
  the mount itself. Where the path is the last thing in the payload
  it runs to the end of the payload; where bytes or a second path
  follow it, a two-byte length precedes it.
- **`attrs`.** Twenty-nine bytes before the path: `[set: u8][mode: u32][uid: u32][gid: u32][atime: 12 bytes][mtime: 12 bytes]`, every integer big-endian, a time `[secs: u64][nanos: u32]`. The bits of `set` say which fields are set: `1` the mode, `2` the owner, `4` the group, `8` the access time, `16` the modification time. A field whose bit is clear is zero and is not set. The mode is the permission bits.
- **A file mount.** For a mount of kind `file`, the path is empty.
