```text
[1][path_len: u16, big-endian][path …][offset: u64, big-endian][bytes …]
```

- **The path.** UTF-8, `/`-separated, with no leading `/`; empty is
  the mount itself. Where the path is the last thing in the payload
  it runs to the end of the payload; where bytes or a second path
  follow it, a two-byte length precedes it.
- **`offset` and the bytes.** The piece to land: the bytes run to the end of the payload and land at `offset` bytes into the file, in place; the file is made if absent, and extended with zero bytes to the offset if shorter. The bytes are at most `CHUNK_SIZE` long.
- **A file mount.** For a mount of kind `file`, the path is empty.
