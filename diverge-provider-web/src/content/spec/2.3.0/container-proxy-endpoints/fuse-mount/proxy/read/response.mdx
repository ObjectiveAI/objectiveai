```text
[0][bytes …]    the file; empty is a file
[1]             nothing at the path
[2][message …]  an error, UTF-8
```

- **The sequence.** Exactly one channel response, the bytes, the absence of the file, or an error, followed
  by the channel response finish.
- **The message.** The bytes after the error byte are UTF-8, not JSON.
- **A finish with nothing.** A channel response finish that no
  channel response precedes states that the server did not serve the
  ask. The proxy does not ask again.
