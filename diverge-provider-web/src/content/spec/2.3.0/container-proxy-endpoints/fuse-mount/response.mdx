```text
[0]             ok: the mount is serving
[1][message …]  not made: why not, UTF-8
```

- **The sequence.** Exactly one response whose first byte is `0`, and
  no response finish for the life of the server; or exactly one
  response whose first byte is `1`, followed by the response finish.
- **The message.** The bytes after the byte `1` are UTF-8, not JSON:
  the reason the mount was not made.
- **A finish with nothing.** A response finish that no response
  precedes states that the server could not read the request.
