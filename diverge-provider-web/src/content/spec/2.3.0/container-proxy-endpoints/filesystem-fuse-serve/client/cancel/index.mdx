The client opens this channel to end the FUSE serve. The server serves no
ask opened after the cancel, answers every ask still open, finishes
every filetree channel of the scope, and sends the response finish on
the scope. The server drops every watch the scope held and changes
nothing in the container.

- **The request.** The tag byte `9` and nothing after it.
  [Request](/container-proxy-endpoints/filesystem-fuse-serve/client/cancel/request/) states its form.
- **The response.** Nothing. [Response](/container-proxy-endpoints/filesystem-fuse-serve/client/cancel/response/)
  states what the server sends instead.
- **Once.** A second cancel on one scope changes nothing.
