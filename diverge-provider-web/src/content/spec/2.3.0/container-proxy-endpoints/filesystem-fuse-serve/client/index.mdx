The client opens each of these channels on the scope, as
[Channels](/frames/channels/) provides, after the server's `Serving`.
The payload of the channel request begins with one tag byte
designating the channel; the remainder is the channel's request, which
names no subtree: the scope is the subtree. The channel request is,
byte for byte, the channel request of a
[volumes::fuse_serve](/endpoints/volumes-fuse-serve/client/) scope: tags `0`
through `8` are the asks of a FUSE mount's scope on the container
proxy — the same tags, the same forms — tag `9` is the stop, and tag
`10` is the filetree. The server answers each ask on its channel with
exactly one channel response and the channel response finish, answers
the filetree with a stream that ends with the scope, and answers a
channel request that does not decode by a channel response finish
that no channel response precedes.

| Tag | Channel |
|-----|---------|
| `0` | [read](/container-proxy-endpoints/filesystem-fuse-serve/client/read/) |
| `1` | [write](/container-proxy-endpoints/filesystem-fuse-serve/client/write/) |
| `2` | [list](/container-proxy-endpoints/filesystem-fuse-serve/client/list/) |
| `3` | [remove](/container-proxy-endpoints/filesystem-fuse-serve/client/remove/) |
| `4` | [rename](/container-proxy-endpoints/filesystem-fuse-serve/client/rename/) |
| `5` | [mkdir](/container-proxy-endpoints/filesystem-fuse-serve/client/mkdir/) |
| `6` | [stat](/container-proxy-endpoints/filesystem-fuse-serve/client/stat/) |
| `7` | [truncate](/container-proxy-endpoints/filesystem-fuse-serve/client/truncate/) |
| `8` | [setattr](/container-proxy-endpoints/filesystem-fuse-serve/client/setattr/) |
| `9` | [stop](/container-proxy-endpoints/filesystem-fuse-serve/client/stop/) |
| `10` | [filetree](/container-proxy-endpoints/filesystem-fuse-serve/client/filetree/) |
