order: 1
draft: false
---

```text
[8][request JSON …]
```

- **`cols`.** An integer from `0` to `65535`: the number of characters
  across one line of the terminal.
- **`rows`.** An integer from `0` to `65535`: the number of lines down
  the terminal.
- **Malformed.** A payload that does not decode as stated is answered
  by a response finish that no response precedes.
