The client opens each of these channels on the scope, as
[Channels](/frames/channels/) provides. The payload of the channel
request begins with one tag byte designating the channel; the remainder
is the channel's request. The server serves the channels in the order
it receives them, and answers a channel request that does not decode by
a channel response finish that no channel response precedes.

| Tag | Channel |
|-----|---------|
| `0` | [stdin](/container-proxy-endpoints/terminal/client/stdin/) |
| `1` | [resize](/container-proxy-endpoints/terminal/client/resize/) |
| `2` | [stop](/container-proxy-endpoints/terminal/client/stop/) |

The channel request is defined by `diverge-sdk-rs/src/shared/containers/terminal/input.rs`:

```rust include=diverge-sdk-rs/src/shared/containers/terminal/input.rs
```
