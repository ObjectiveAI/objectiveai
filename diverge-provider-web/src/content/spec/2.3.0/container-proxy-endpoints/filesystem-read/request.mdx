```text
[4][request JSON …]
```

- **`path`.** An array of strings: the components of the file's path
  from the root of the container. Never empty; no component empty,
  `.` or `..`, or containing `/` or NUL.
- **Malformed.** A payload that does not decode as stated is answered
  by a response finish that no response precedes.
