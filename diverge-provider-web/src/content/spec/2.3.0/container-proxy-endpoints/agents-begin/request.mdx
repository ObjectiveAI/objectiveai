```text
[0][request JSON …]
```

- **`arguments`.** A JSON value: the `arguments` of the
  [containers::agents::run](/endpoints/containers-agents-run/request/)
  request that made the container, verbatim. What the value may be,
  the image's `/DIVERGE.md` defines, and the
  [info](/container-proxy-endpoints/agents-begin/client/info/) channel
  answers.
- **`template`.** A string: the `template` of the
  [containers::agents::run](/endpoints/containers-agents-run/request/)
  request that made the container, verbatim: the id of the template
  the container is made from, which the server hands to the
  container's program with the arguments and reads for nothing
  else.
- **No secret.** The request carries no secret. Which secrets the
  container's program takes is its own answer, carried in the
  `secrets` of `Begun`; their values follow on a
  [secrets](/container-proxy-endpoints/agents-begin/client/secrets/)
  channel, the first of them before the run's id.
- **Once, and first.** The client sends this request before any other
  request on the connection, and never again on it.
- **Malformed.** A payload that does not decode as stated is answered
  by a response finish that no response precedes.
