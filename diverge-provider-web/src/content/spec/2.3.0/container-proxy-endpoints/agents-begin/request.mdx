```text
[0][request JSON …]
```

- **`arguments`.** A JSON value: the `arguments` of the
  [containers::agents::run](/endpoints/containers-agents-run/request/)
  request that made the container, verbatim. What the value may be,
  the image defines, and the [schema](/container-proxy-endpoints/agents-begin/client/schema/) channel
  answers.
- **`image`.** An object of two fields, `{"name":…,"digest":…}`:
  the `image` of that request, verbatim. It is what the server puts
  under `_meta` on every MCP exchange it relays, as the
  [mcp-call-tool](/container-proxy-endpoints/agents-begin/server/mcp-call-tool/) channel and its
  siblings state.
- **Once, and first.** The client sends this request before any other
  request on the connection, and never again on it.
- **Malformed.** A payload that does not decode as stated is answered
  by a response finish that no response precedes.
