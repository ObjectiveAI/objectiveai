The proxy opens this channel when a program in the container locks a key
of the vault. The ask is sent verbatim; the server's one answer is
relayed back to the program verbatim.

- **The request.** The tag byte `5` followed by the ask.
  [Request](/container-proxy-endpoints/agents-begin/proxy/vault-lock/request/) states its form.
- **The response.** Exactly one channel response and the channel
  response finish. [Response](/container-proxy-endpoints/agents-begin/proxy/vault-lock/response/) states the
  sequence.
- **No repetition.** The proxy sends the ask exactly once. A channel
  that ends without a finish is not asked again.
- **The meaning.** What the ask means, and what its answer means,
  [Vault lock](/endpoints/containers-agents-run/server/vault-lock/) states; the proxy decides nothing
  about a key.
