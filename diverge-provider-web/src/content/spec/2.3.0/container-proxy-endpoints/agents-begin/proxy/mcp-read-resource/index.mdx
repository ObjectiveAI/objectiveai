The proxy opens this channel when a program in the container asks,
of the MCP server the proxy serves it, for one resource of the servers of the client, read. The params are sent
verbatim; the server's one answer is relayed back.

- **The request.** The tag byte `10` followed by the params of the
  MCP method `resources/read` as JSON. [Request](/container-proxy-endpoints/agents-begin/proxy/mcp-read-resource/request/)
  states its form.
- **The response.** Exactly one channel response, the result or an
  error, and the channel response finish.
  [Response](/container-proxy-endpoints/agents-begin/proxy/mcp-read-resource/response/) states the sequence.
- **No repetition.** The proxy sends the exchange exactly once. A
  channel that ends without a finish is not asked again.
- **The meaning.** What the exchange is,
  [MCP read resource](/endpoints/containers-agents-run/server/mcp-read-resource/) states.
