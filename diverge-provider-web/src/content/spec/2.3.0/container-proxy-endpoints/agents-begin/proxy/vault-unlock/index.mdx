The proxy opens this channel when a program in the container unlocks a key
of the vault. The ask is sent verbatim; the server's one answer is
relayed back to the program verbatim.

- **The request.** The tag byte `6` followed by the ask.
  [Request](/container-proxy-endpoints/agents-begin/proxy/vault-unlock/request/) states its form.
- **The response.** Exactly one channel response and the channel
  response finish. [Response](/container-proxy-endpoints/agents-begin/proxy/vault-unlock/response/) states the
  sequence.
- **No repetition.** The proxy sends the ask exactly once. A channel
  that ends without a finish is not asked again.
- **The meaning.** What the ask means, and what its answer means,
  [Vault unlock](/endpoints/containers-agents-run/server/vault-unlock/) states; the proxy decides nothing
  about a key.
