The proxy opens this channel when a program in the container asks,
of the MCP server the proxy serves it, for the resources the servers of the client offer. The params are sent
verbatim; the server's one answer is relayed back.

- **The request.** The tag byte `8` followed by the params of the
  MCP method `resources/list` as JSON. [Request](/container-proxy-endpoints/agents-begin/proxy/mcp-list-resources/request/)
  states its form.
- **The response.** Exactly one channel response, the result or an
  error, and the channel response finish.
  [Response](/container-proxy-endpoints/agents-begin/proxy/mcp-list-resources/response/) states the sequence.
- **No repetition.** The proxy sends the exchange exactly once. A
  channel that ends without a finish is not asked again.
- **The meaning.** What the exchange is,
  [MCP list resources](/endpoints/containers-agents-run/server/mcp-list-resources/) states.
