title: 'Response'
summary: 'The sequence of channel responses that answers the channel, what ends it, and what a finish with nothing before it means.'
order: 2
draft: false
---

```text
[0]                  delivered: the agent's program has every message of the batch, or the structured decision
[2][error JSON …]    the container refused the request, or no run could start on it
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server did not serve the batch.
- **One fate.** The channel response is the fate of every message of
  the batch. The server answers no message of a batch apart from the
  others.
- **Delivered.** The byte `0` states that the program of the agent
  holds every message of the batch: the `/run` that carried it answered with a
  `2xx` status, or the `/enqueue` that carried it to the loop in
  flight answered with the status `204`. The proxy does not wait for
  a turn. For a structured decision, the byte `0` states that the
  `/run` the server started on it answered with a `2xx` status; the
  server sends it no earlier, and so sends it only after every
  request of a lower index has been handed over and the run before it
  has ended. The byte `1` is not sent.
- **The error.** The byte `2` states that the container refused the
  batch's content — at the start of a loop, or at the delivery of a
  queued batch to the loop in flight — or that a loop the batch
  was to start did not start; the bytes after it are the container's
  own words, as JSON. A batch the container refuses is not offered
  again.
