draft: false
---

```text
[0]                  delivered: a loop took the message
[1]                  dequeued: the message was withdrawn first
[2][error JSON …]    the container refused the message, or no loop could start on it
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server did not serve the message.
- **The error.** The byte `2` states that the container refused the
  message's content — at the start of a loop, or at the delivery of a
  queued message into the loop in flight — or that a loop the message
  was to start did not start; the bytes after it are the container's
  own words, as JSON. A message the container refuses is not offered
  again.
