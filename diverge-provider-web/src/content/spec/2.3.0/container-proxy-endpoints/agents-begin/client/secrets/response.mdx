draft: false

```text
[0]                  fed: the program holds the values
[1][error JSON …]    not fed: the program refused the values
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server did not serve the feed.
- **Fed.** The byte `0` states that the container's program holds the
  values, and nothing follows the byte. The server sends it only
  after the program has taken the values, and from that moment
  delivers messages to the program.
- **The error.** The byte `1` states that the program refused the
  values; the bytes after it are exactly one JSON value in the form
  defined on the [volumes::list response](/endpoints/volumes-list/response/)
  page, the program's own words. The server delivers nothing to the
  program until a later channel of this section is answered `Fed`.
