```text
[2][connection_id: u32, big-endian]
```

- **`connection_id`.** The id the server announced on its own daemon
  channel, as four bytes, big-endian.
- **Malformed.** A channel request whose payload is not exactly four
  bytes after the tag is answered by a channel response finish that
  no channel response precedes, and the server does nothing else for
  it.
