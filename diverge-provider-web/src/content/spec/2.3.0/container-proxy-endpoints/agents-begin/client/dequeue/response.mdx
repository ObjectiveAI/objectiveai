```text
[0]                  one or more messages waited under the key, and are withdrawn
[1]                  nothing waited under the key
[2][error JSON …]    the container could not say
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server did not serve the request.
