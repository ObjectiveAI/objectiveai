The client opens each of these channels on the scope, as
[Channels](/frames/channels/) provides. The payload of the channel request begins with one tag byte designating the channel; the remainder is the channel's request. The client opens no channel on the scope before the `Begun` response. The server serves each as
its section states, and answers a channel request that does not decode
by a channel response finish that no channel response precedes.

| Tag | Channel |
|-----|---------|
| `0` | [postgres](/container-proxy-endpoints/agents-begin/client/postgres/) |
| `1` | [schema](/container-proxy-endpoints/agents-begin/client/schema/) |
| `2` | [enqueue](/container-proxy-endpoints/agents-begin/client/enqueue/) |
| `3` | [dequeue](/container-proxy-endpoints/agents-begin/client/dequeue/) |
