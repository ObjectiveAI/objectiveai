```text
[0][connection_id: u32, big-endian]
```

- **`connection_id`.** Four bytes, big-endian, the id of the
  connection.

The channel request is defined by `diverge-sdk-rs/src/container_proxy/outside/agents/begin/server/channel_request/frame.rs`:


```rust include=diverge-sdk-rs/src/shared/containers/postgres/request/postgres.rs
```
