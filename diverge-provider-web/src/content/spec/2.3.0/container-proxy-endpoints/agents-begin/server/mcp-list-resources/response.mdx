```text
[0][result JSON …]    the result of the method
[1][error JSON …]     the MCP error
```

- **The sequence.** Exactly one channel response, the result or the
  error, followed by the channel response finish.
- **A finish with nothing.** A channel response finish that no
  channel response precedes states that the client did not serve the
  ask. The server does not ask again.
