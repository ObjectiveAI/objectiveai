The server opens each of these channels on the scope, as
[Channels](/frames/channels/) provides, when its section states. The payload of the channel request begins with one tag byte designating the channel; the remainder is the channel's request. The server opens no channel on the scope before it has sent the `Begun` response.
The client answers on the channel; what the server does with the
answer, its section states.

| Tag | Channel |
|-----|---------|
| `0` | [postgres](/container-proxy-endpoints/agents-begin/server/postgres/) |
| `1` | [command](/container-proxy-endpoints/agents-begin/server/command/) |
| `2` | [vault-get](/container-proxy-endpoints/agents-begin/server/vault-get/) |
| `3` | [vault-set](/container-proxy-endpoints/agents-begin/server/vault-set/) |
| `4` | [vault-delete](/container-proxy-endpoints/agents-begin/server/vault-delete/) |
| `5` | [vault-lock](/container-proxy-endpoints/agents-begin/server/vault-lock/) |
| `6` | [vault-unlock](/container-proxy-endpoints/agents-begin/server/vault-unlock/) |
| `7` | [mcp-list-tools](/container-proxy-endpoints/agents-begin/server/mcp-list-tools/) |
| `8` | [mcp-list-resources](/container-proxy-endpoints/agents-begin/server/mcp-list-resources/) |
| `9` | [mcp-call-tool](/container-proxy-endpoints/agents-begin/server/mcp-call-tool/) |
| `10` | [mcp-read-resource](/container-proxy-endpoints/agents-begin/server/mcp-read-resource/) |
| `11` | [mcp-notifications](/container-proxy-endpoints/agents-begin/server/mcp-notifications/) |
