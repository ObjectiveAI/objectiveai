```text
[7][params JSON …]
```

- **The params.** The params of the MCP method `tools/list`, as JSON,
  as the program sent them, with one addition.
- **The image.** The server sets `_meta["diverge.network/image"]` on
  the params to an object of two fields, `{"name":…,"digest":…}`:
  the `image` the begin request carried, verbatim. A value the
  program set under that key is replaced. Every other member of
  `_meta`, and every other member of the params, is sent as the
  program sent it.
