summary: 'The sequence of channel responses that answers the channel, what ends it, and what a finish with nothing before it means.'
order: 2
draft: false
---

```text
[0]                  delivered: a loop took the message
[1]                  dequeued: the message was withdrawn first
[2][error JSON …]    no loop could start on the message
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the proxy did not serve the message.
- **The error.** The byte `2` states only that a loop the message was
  to start did not start; the bytes after it are the container's own
  words, as JSON. A message queued behind a running loop is never
  answered by the byte `2`.
