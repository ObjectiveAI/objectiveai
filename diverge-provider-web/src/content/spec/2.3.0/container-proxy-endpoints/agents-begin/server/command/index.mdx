The server opens this channel when a program in the container asks for
a command to be run. The bytes of the command are sent verbatim.

- **The request.** The tag byte `1` followed by the bytes of the
  command. [Request](/container-proxy-endpoints/agents-begin/server/command/request/) states its form.
- **The response.** One channel response per item, an error last
  when the client sends one, and the channel response finish.
  [Response](/container-proxy-endpoints/agents-begin/server/command/response/) states the sequence.
- **No repetition.** The server sends a command exactly once. A
  channel that ends without a finish is not asked again.
- **The command.** What a command is, and what an item is,
  [Command](/endpoints/containers-agents-run/server/command/) states; the server reads neither.
