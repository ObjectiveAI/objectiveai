The server opens this channel to withdraw every message waiting for
the agent: those the proxy holds, and those the loop in flight holds
and has not taken. A message the loop has taken stays taken.

- **The request.** The tag byte `3` and nothing more.
  [Request](/container-proxy-endpoints/agents-begin/server/dequeue/request/) states its form.
- **The response.** Exactly one channel response and the channel
  response finish. [Response](/container-proxy-endpoints/agents-begin/server/dequeue/response/) states the
  sequence.
- **The messages withdrawn.** Each message withdrawn is answered on
  its own [enqueue](/container-proxy-endpoints/agents-begin/server/enqueue/) channel with the byte `1`.
