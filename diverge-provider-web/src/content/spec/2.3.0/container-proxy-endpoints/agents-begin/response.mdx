```text
[0][tools JSON …]    begun: the container holds its arguments, and these are its tools
[1][error JSON …]    not begun: the connection had begun, or the arguments were refused
[2][chunk JSON …]    one chunk of the conversation
```

- **The sequence.** Exactly one response whose first byte is `0`,
  followed by zero or more responses whose first byte is `2`, in the
  order the container produced them, followed by the response
  finish when the server ends; or exactly one response whose first
  byte is `1`, followed by the response finish. The server sends no
  response whose first byte is `2` before `Begun`, and none after the
  finish.
- **The tools.** The bytes after the byte `0` are a JSON array of
  the tools the container's program answered its registration with,
  each as the [tools](/endpoints/containers-agents-run/server/tools/)
  channel of the run defines one, in the order the program declared
  them; empty when the program declared none. The server sends the
  array exactly as the program produced it.
- **The chunk.** The bytes after the byte `2` are one chunk as the
  [containers::agents::run response](/endpoints/containers-agents-run/response/)
  defines it, as JSON, which the server sends as the agent's server
  produced it, with one addition. The first chunks of a loop are the
  user parts of the message it started on — one chunk per content
  block, each carrying the message's `key` — or of every message it
  started on, in the order sent.
- **The image.** The server sets `_meta["diverge.network/image"]` on
  each chunk to an object of two fields, `{"name":…,"digest":…}`:
  the `image` the begin request carried, verbatim. A value the
  agent's server set under that key is replaced. Every other member
  of `_meta`, and every other member of the chunk, is sent as the
  agent's server produced it. A chunk that is not a JSON object is
  sent as the agent's server produced it.
- **The error.** After the byte `1`, exactly one JSON value in the
  form defined on the [volumes::list response](/endpoints/volumes-list/response/)
  page. Refused arguments carry the container's own words.
- **A finish with nothing.** A response finish that no response
  precedes states that the server could not read the request.
