```text
[6][request JSON …]
```

- **`path`.** An array of strings: the components of the directory
  to serve, from the root of the container. An empty array names the
  root of the container. No component is empty, `.` or `..`, or
  contains `/` or NUL; a path with such a component is answered with
  an error, not as malformed.
- **No mode, and nothing left out.** The request carries nothing
  else: a container has no mode, and the server leaves out of a
  serve what it leaves out of every tree.
- **Malformed.** A payload that does not decode as stated is answered
  by a response finish that no response precedes.
