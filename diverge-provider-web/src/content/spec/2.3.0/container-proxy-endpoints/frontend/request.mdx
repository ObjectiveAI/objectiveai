title: 'Request'
summary: 'The payload is the tag byte 9 followed by the head of one HTTP request as JSON: method, path and headers.'

draft: false
---

```text
[9][request JSON …]
```

- **`method`.** A string: the request's method, as HTTP writes it.
- **`path`.** A string: the request's path and query, as the request
  line of an HTTP/1.1 request carries them.
- **`headers`.** An array of two-element arrays of strings, each a
  header name and its value, in the order the request carries them. A
  name may occur more than once. Absent, the request carries no
  header.
- **The path rule.** `path` is the string `/frontend`, or a string that
  begins with `/frontend/` or with `/frontend?`. No segment of the
  part of `path` before the first `?` is `.` or `..`, a segment being
  the text between two consecutive `/` characters or after the last.
  `path` contains no `\` character and none of the sequences `%2e`,
  `%2f` and `%5c`, compared without regard to case.
- **Malformed.** A payload that does not decode as stated is answered
  by a response finish that no response precedes.
