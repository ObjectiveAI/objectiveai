The client ends the request's body by opening this channel. The
server ends the body it sends to the program and answers with the
channel response finish.

- **The request.** [Request](/container-proxy-endpoints/frontend/client/end/request/) states its form.
- **The response.** [Response](/container-proxy-endpoints/frontend/client/end/response/) states the sequence.
