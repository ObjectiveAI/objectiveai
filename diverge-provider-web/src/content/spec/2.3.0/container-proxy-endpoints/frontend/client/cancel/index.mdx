The client ends the request by opening this channel. The server ends
its request to the program, answers with the channel response finish,
and finishes the scope.

- **The request.** [Request](/container-proxy-endpoints/frontend/client/cancel/request/) states its form.
- **The response.** [Response](/container-proxy-endpoints/frontend/client/cancel/response/) states the sequence.
