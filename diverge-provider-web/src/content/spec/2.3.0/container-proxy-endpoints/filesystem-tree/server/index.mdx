The server opens each of these channels on the scope, as
[Channels](/frames/channels/) provides. A tree defines one channel, and its channel request carries no tag: the payload is empty. The proxy serves each as
its section states, and answers a channel request that does not decode
by a channel response finish that no channel response precedes.

|-----|---------|
| — | [stop](/container-proxy-endpoints/filesystem-tree/server/stop/) |
