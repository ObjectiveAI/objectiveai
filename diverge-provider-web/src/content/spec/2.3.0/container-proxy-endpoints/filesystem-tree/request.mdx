```text
[3][request JSON …]
```

- **`ignore`.** An array of paths, each an array of strings: the
  components of a path from the root of the container. An empty path
  is dropped, not read as the root.
- **Always left out.** `/proc`, `/sys` and `/dev`, whether or not the
  request names them.
- **Malformed.** A payload that does not decode as stated is answered
  by a response finish that no response precedes.
