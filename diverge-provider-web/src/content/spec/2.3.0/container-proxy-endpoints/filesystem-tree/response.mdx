```text
[0][filetree frame …]    the snapshot, or one change
[1][error JSON …]        the tree cannot be watched
```

- **The sequence.** Zero or more responses whose first byte is `0` —
  the first a snapshot, a snapshot again after lost events, and one
  per change otherwise — followed by the response finish when the
  server has sent the stop or the server ends; or the responses sent
  so far, exactly one response whose first byte is `1`, and the
  response finish.
- **The frame.** The bytes after the byte `0` are one frame of the
  [filetree](/endpoints/containers-agents-run/client/filetree/)
  stream, in the postcard encoding that channel states.
- **A finish with nothing.** A response finish that no response
  precedes states that the server could not read the request.
