```text
[10][params JSON …]
```

- **The params.** The params of the MCP method `resources/read`, as JSON,
  as the program sent them.
- **`_meta`.** The server sets nothing under `_meta`. Every member of
  `_meta`, and every other member of the params, is sent as the
  program sent it.

The channel request is defined by `diverge-sdk-rs/src/container_proxy/outside/endpoints/tools/begin/server/channel_request/frame.rs`:

```rust include=diverge-sdk-rs/src/container_proxy/outside/endpoints/tools/begin/server/channel_request/frame.rs
```

and by `diverge-sdk-rs/src/shared/mcp/read_resource/request/request.rs`:

```rust include=diverge-sdk-rs/src/shared/mcp/read_resource/request/request.rs
```
