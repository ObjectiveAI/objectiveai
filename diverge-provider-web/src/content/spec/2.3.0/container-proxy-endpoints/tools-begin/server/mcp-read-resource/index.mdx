The server opens this channel when a program in the container asks
for one resource of the MCP servers of the caller, read. The params are sent
verbatim; the client's one answer is relayed back.

- **The request.** The tag byte `10` followed by the params of the
  MCP method `resources/read` as JSON. [Request](/container-proxy-endpoints/tools-begin/server/mcp-read-resource/request/)
  states its form.
- **The response.** Exactly one channel response, the result or an
  error, and the channel response finish.
  [Response](/container-proxy-endpoints/tools-begin/server/mcp-read-resource/response/) states the sequence.
- **No repetition.** The server sends the exchange exactly once. A
  channel that ends without a finish is not asked again.
- **The meaning.** What the exchange is,
  [MCP read resource](/endpoints/containers-agents-run/server/mcp-read-resource/) states.
