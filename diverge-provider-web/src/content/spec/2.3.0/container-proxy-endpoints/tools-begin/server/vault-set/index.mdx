The server opens this channel when a program in the container writes a key
of the vault. The ask is sent verbatim; the client's one answer is
relayed back to the program verbatim.

- **The request.** The tag byte `3` followed by the ask.
  [Request](/container-proxy-endpoints/tools-begin/server/vault-set/request/) states its form.
- **The response.** Exactly one channel response and the channel
  response finish. [Response](/container-proxy-endpoints/tools-begin/server/vault-set/response/) states the
  sequence.
- **No repetition.** The server sends the ask exactly once. A channel
  that ends without a finish is not asked again.
- **The meaning.** What the ask means, and what its answer means,
  [Vault set](/endpoints/containers-agents-run/server/vault-set/) states; the server decides nothing
  about a key.
