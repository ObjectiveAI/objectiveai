The server opens this channel for the tools the MCP server of the container offers. The proxy makes the
exchange of the container's MCP server and answers with its result.

- **The request.** The tag byte `1` followed by the params of the
  MCP method `tools/list` as JSON. [Request](/container-proxy-endpoints/tools-begin/server/mcp-list-tools/request/)
  states its form.
- **The response.** Exactly one channel response, the result or an
  error, and the channel response finish.
  [Response](/container-proxy-endpoints/tools-begin/server/mcp-list-tools/response/) states the sequence.
- **The server of the container.** A container whose MCP server
  cannot be reached is answered by the error. The error an MCP server
  states is sent as itself, its code included.
