```text
[0][notification JSON …]    zero or more
[1][error JSON …]           last
```

- **The sequence.** Zero or more channel responses whose first byte
  is `0`, each one notification, in order. An error, when the client
  sends one, is the last channel response. The channel response
  finish follows the last channel response.
- **A finish with nothing.** A channel response finish that no
  channel response precedes states that the client did not serve the
  ask. The server does not ask again.
