```text
[0][connection_id: u32, big-endian]
```

- **`connection_id`.** The id the proxy announced on its own postgres
  channel, as four bytes, big-endian.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the proxy does nothing else for it.
