```text
[1][request JSON …]
```

- **`arguments`.** A JSON value: the `arguments` of the
  [containers::tools::run](/endpoints/containers-tools-run/request/)
  request that made the container, verbatim. What the value may be,
  the image defines, and the [schema](/container-proxy-endpoints/tools-begin/client/schema/) channel
  answers.
- **`secrets`.** A JSON object: the `secrets` of the
  [containers::tools::run](/endpoints/containers-tools-run/request/)
  request that made the container, verbatim, each member a secret's
  name to its value, which the server hands to the container's
  program with the arguments and reads for nothing else. Absent, the
  empty object.
- **`template`.** A string: the `template` of the
  [containers::tools::run](/endpoints/containers-tools-run/request/)
  request that made the container, verbatim: the id of the template
  the container is made from, which the server hands to the
  container's program with the arguments and the secrets and reads
  for nothing else.
- **Once, and first.** The client sends this request before any other
  request on the connection, and never again on it.
- **Malformed.** A payload that does not decode as stated is answered
  by a response finish that no response precedes.
