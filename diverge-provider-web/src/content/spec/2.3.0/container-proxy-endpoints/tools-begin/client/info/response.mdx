title: 'Response'
summary: 'The sequence of channel responses that answers the channel, what ends it, and what a finish with nothing before it means.'
order: 2
draft: false
---

```text
[0][document JSON …]    the image's /DIVERGE.md, parsed
[1]                     the image ships no /DIVERGE.md
[2][error JSON …]       the file could not be read, or is not a document
```

- **The sequence.** Exactly one channel response, followed by the
  channel response finish. A channel response finish that no channel
  response precedes states that the server did not serve the
  question.
- **The document.** The byte `0` is followed by exactly one JSON
  object of at least three and at most six members, which the server reads from the file. The
  file begins with a line that is exactly `---`; the lines after it,
  up to the next line that is exactly `---`, are the frontmatter. The
  frontmatter is exactly one JSON object with the members `name`, a
  string, which the server sends as `name`, the image's own name; and
  `schema`, a JSON object, which the server sends as `schema`, the
  JSON Schema of the container's `arguments`; and at most three further
  members: `frontend`, a boolean; `chat`; and `structured_decisions`.
  The value of `chat` is the boolean `false` or an object of exactly
  one member, `prompt_modalities`. The value of
  `structured_decisions` is the boolean `false` or an object of
  exactly two members, `prompt_modalities` and `choice_modalities`.
  Each of those three members is an object of exactly three members,
  `image`, `audio` and `file`, each a boolean. The frontmatter has no
  other member, and a frontmatter in which `chat` or
  `structured_decisions` is `true` is not a document.
  The server sends `frontend` with the value `true` when the
  frontmatter's `frontend` is `true`, and omits it otherwise. The
  server sends `chat` with the frontmatter's object when the
  frontmatter's `chat` is an object, and omits it otherwise. The
  server sends `structured_decisions` with the frontmatter's object
  when the frontmatter's `structured_decisions` is an object, and
  omits it otherwise. Every byte
  after the closing line is `body`, a string, verbatim. The server
  reads the file as UTF-8 and reads no member further.
- **Missing.** The byte `1` states that the image ships no
  `/DIVERGE.md`. Nothing follows the byte. That is a fact about the
  image and not a failure.
- **The error.** The byte `2` states that the file is at the root and
  the server could not read it, or that the file is not a document:
  it does not begin with a line that is exactly `---`, no later line
  is exactly `---`, the frontmatter is not a JSON object with
  exactly the members `name`, a string, and `schema`, or `schema` is
  not an object. The bytes after it are exactly one JSON
  value in the form defined on the [volumes::list response](/endpoints/volumes-list/response/) page. No error of
  this channel is the container's program's: the server asks it
  nothing.
