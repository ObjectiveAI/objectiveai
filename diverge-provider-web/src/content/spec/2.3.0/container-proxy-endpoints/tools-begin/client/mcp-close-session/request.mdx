```text
[9]{"session": …}
```

- **The session.** The member `session` is the caller whose MCP
  session the channel closes, as the daemon attests it: the object the
  key `diverge.network` holds on a request's `_meta`, an agent or a
  client. Two callers are one session when their agents have one
  template and one index, or their clients one issuer, one subject and
  one `scope`. A client's `scope` is a string.
- **Payload.** The remainder is one JSON object with exactly one
  member, `session`.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
