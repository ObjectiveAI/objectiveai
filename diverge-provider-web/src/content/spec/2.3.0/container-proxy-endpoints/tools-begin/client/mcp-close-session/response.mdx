```text
[0]                   closed
```

- **Closed.** The payload is exactly the byte `0`, and nothing follows
  it. The server sends it once the session is removed, and for a
  caller with no session open.
- **The sequence.** Exactly one channel response, closed, followed by
  the channel response finish. A channel response finish that no
  channel response precedes states that the server did not serve the
  close.
- **The error.** The frame defines the byte `1`, followed by an MCP
  error as JSON. The server sends no such channel response on this
  channel.
