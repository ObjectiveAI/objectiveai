```text
[0][notification JSON …]    zero or more
[1][error JSON …]           the client of the container cannot be reached
```

- **The sequence.** Zero or more channel responses whose first byte
  is `0`, each one notification, in order, and no finish while the
  connection lives; or exactly one channel response whose first byte
  is `1`, sent before any notification, followed by the channel
  response finish.
- **Lost notifications.** A notification the container's MCP server
  sent while the channel could not keep pace is not sent; the
  sequence does not report the loss.
- **The image.** The server sets `_meta["diverge.network/image"]` in
  the params of each notification to an object of two fields,
  `{"name":…,"digest":…}`: the `image` the begin request carried,
  verbatim. A value the container's server set under that key is
  replaced. Every other member of the notification is sent as the
  container's server sent it.
