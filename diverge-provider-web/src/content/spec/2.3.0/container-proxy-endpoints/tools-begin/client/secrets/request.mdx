```text
[8][values JSON …]
```

- **The values.** A JSON object whose every member is a secret's
  name, as the container's program declared it in the `secrets` of
  `Begun`, to its value, any JSON value, in the order declared: every
  name the program declared, a `fixed` one to a value read for it and
  a `rotating` one to the value locked to the container until the
  next `Inactive`. The server hands the object to the program as it
  is and does not read it.
- **Malformed.** A channel request whose payload does not decode as
  stated is answered by a channel response finish that no channel
  response precedes, and the server does nothing else for it.
