```text
[0][result JSON …]    the result of the method
[1][error JSON …]     the MCP error
```

- **The sequence.** Exactly one channel response, the result or the
  error, followed by the channel response finish. A channel response
  finish that no channel response precedes states that the server did
  not serve the exchange.
- **The image.** The server sets `_meta["diverge.network/image"]` on
  the result, and on each tool of the result, to an object of two fields,
  `{"name":…,"digest":…}`: the `image` the begin request carried,
  verbatim. A value the container's server set under that key is
  replaced. Every other member of `_meta`, and every other member of
  the result, is sent as the container's server sent it. The error
  is sent as the container's server sent it.
