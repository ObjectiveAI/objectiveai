The client opens this channel as its half of a daemon connection the
server announced on a [daemon](/container-proxy-endpoints/tools-begin/server/daemon/) channel of its own, quoting
the connection id. The server sends on it everything the program
sends.

- **The request.** The tag byte `2` followed by the connection id,
  four bytes. [Request](/container-proxy-endpoints/tools-begin/client/daemon/request/) states its
  form.
- **The response.** The frames the program sent, as channel responses,
  each one client frame, and the channel response finish when the
  program's socket ends. [Response](/container-proxy-endpoints/tools-begin/client/daemon/response/)
  states the sequence.
- **Nothing is lost.** The server reads nothing from the program
  before this channel opens, and sends what the program sends from the
  moment it does, in order.
- **One half per connection.** A connection id the server did not
  announce, and an id whose half was already opened, are answered by
  a channel response finish that no channel response precedes.
