The client opens this channel to hear what the container's MCP server
says on its own account. The server relays each notification as one
channel response from the moment the channel opens.

- **The request.** The tag byte `6` and nothing more.
  [Request](/container-proxy-endpoints/tools-begin/client/mcp-notifications/request/) states its form.
- **The response.** One channel response per notification, for as
  long as the connection lives, or exactly one error and the channel
  response finish. [Response](/container-proxy-endpoints/tools-begin/client/mcp-notifications/response/)
  states the sequence.
- **Many channels.** The client may open this channel more than
  once; each channel hears every notification from the moment it
  opened.
