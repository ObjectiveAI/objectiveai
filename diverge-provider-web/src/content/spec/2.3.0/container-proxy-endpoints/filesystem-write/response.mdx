```text
[0]                  written: the file is at the path
[1][error JSON …]    not written, and nothing partial is
```

- **The sequence.** Exactly one response, followed by the response
  finish. The response is sent only once the content channel has
  finished, or the write has failed.
- **A finish with nothing.** A response finish that no response
  precedes states that the proxy could not read the request.
