The proxy opens each of these channels on the scope, as
[Channels](/frames/channels/) provides, when its section states. A write defines one channel, and its channel request carries no tag: the payload is empty.
The server answers on the channel; what the proxy does with the
answer, its section states.

| — | [content](/container-proxy-endpoints/filesystem-write/proxy/content/) |
