The server opens `/tool/read-resource` and sends exactly one message, the
params defined below as JSON — the params of the MCP method
`resources/read`. The proxy sends exactly one message and closes the
connection. The message is the response frame defined below: its
first byte is `0`, followed by the result as JSON, or `1`, followed by
the error as JSON. [Tool](/proxy/tool/) states what the proxy sends
when the params do not parse and when the MCP server of the container
cannot be reached.
