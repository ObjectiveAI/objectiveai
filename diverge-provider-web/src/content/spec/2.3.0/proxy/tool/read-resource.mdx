The server opens `/tool/read-resource` and sends one message, the params
below as JSON — the params of MCP's `resources/read`. The container answers
with exactly one message — the response frame below, its first byte
`0` for a result or `1` for an error, the rest that variant's JSON —
then the close. See [Tool](/proxy/tool/) for what is answered when
the params do not parse or the container's server cannot be reached.
