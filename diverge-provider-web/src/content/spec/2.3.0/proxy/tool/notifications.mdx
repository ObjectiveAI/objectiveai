The server opens `/tool/notifications` and sends no message. The
proxy sends one message per notification that the MCP server of the
container sends from that moment on, for as long as the path lives.
Each message is the response frame defined below, with first byte `0`
followed by the notification as JSON. When the MCP server of the
container cannot be reached, the proxy sends exactly one message,
with first byte `1` followed by the error as JSON, and closes the
connection.

- **From the opening on.** The proxy does not send a notification
  that occurred before the path was opened.
- **The server closes.** The path lives until the server closes it.
  The proxy closes it only in the case of the error above.
