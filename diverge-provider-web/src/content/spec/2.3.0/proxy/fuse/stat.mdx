The ask is kind `18` on [`/requests`](/proxy/requests/):

```text
[18][id_len: u16, big-endian][id …][path …]
```

The server answers on `/fuse/stat/{channel}` by sending exactly one
message and closing the connection. In the message, a first byte of `0` is followed by the nine bytes of a stat, the kind and the size; a first byte of `1` states that nothing is held at the path; a first byte of `2` is followed by a message stating why the stat failed.
A path that the proxy or the server closes cleanly with no message
before the close states that the ask was not served. An abrupt end of the path leaves the operation failed, and
the proxy does not ask it again, as [FUSE](/proxy/fuse/) provides.

- **Absence.** On a file mount, `1` states that the caller holds
  nothing under the id yet; the file reads as empty, and the first
  `write` creates it.

The ask is the target defined on [FUSE](/proxy/fuse/): the id of the mount and the path of the entry.
