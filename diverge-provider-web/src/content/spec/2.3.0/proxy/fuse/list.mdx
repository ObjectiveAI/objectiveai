The ask is kind `14` on [`/requests`](/proxy/requests/):

```text
[14][id_len: u16, big-endian][id …][path …]
```

The server answers on `/fuse/list/{channel}` by sending exactly one
message and closing the connection. In the message, a first byte of `0` is followed by a count and that many entries; a first byte of `1` states that no directory is held at the path; a first byte of `2` is followed by a message stating why the listing failed.
A path that the proxy or the server closes cleanly with no message
before the close states that the ask was not served. An abrupt end of the path leaves the operation failed, and
the proxy does not ask it again, as [FUSE](/proxy/fuse/) provides.

- **Names and kinds.** An entry carries its name, one path component
  that is never `.` or `..`, and its kind. An entry's size is
  obtained with `stat`.

The ask is the target defined on [FUSE](/proxy/fuse/): the id of the mount and the path of the entry.
