The server opens `/fuse/mount` and sends exactly one message, the
request below as JSON, naming one mount. The container makes the
mount and answers with exactly one message — `0`, the mount is
serving; or `1` and a message, the mount was not made — then the
close. The answer is not sent before the mount is complete.

```text
server → container:   [request JSON]            once
container → server:   [0] | [1][message …]      once the mount is complete, then the close
```

- **One mount per opening.** The path accepts every opening the
  server makes; each carries one mount.
- **Not made.** A path that is empty, or has a component that is
  empty, `.` or `..`; a path at which a mount is already held; a
  mount point that could not be made; a host without FUSE; a session
  that would not start — each is `1` and a message.
- **Could not serve.** A close before the request, or a request that
  does not decode, is answered with the clean close and nothing
  before it.
- **For the proxy's life.** A mount made is held until the proxy
  ends. Nothing unmounts one. An abrupt end is a mount whose fate the
  server did not hear; nothing retries it.
- **Before everything.** The server makes every mount before it
  registers the agent and before it opens any filetree, so what a
  program finds at the path is the mount, and what a tree reports
  never includes one.

The request is `diverge-provider-sdk/src/container_proxy/fuse/mount/request/request.rs`:

```rust include=diverge-provider-sdk/src/container_proxy/fuse/mount/request/request.rs
```

Its `kind` is the `Kind` of [FUSE](/proxy/fuse/), as JSON: `"file"`
or `"directory"`. The answer is the ack of [FUSE](/proxy/fuse/).
