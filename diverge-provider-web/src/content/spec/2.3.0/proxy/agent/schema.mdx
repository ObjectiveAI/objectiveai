The server opens `/agent/schema` and sends no message. The proxy sends
exactly one message and closes the connection. In the message, a
first byte of `0` is followed by a JSON Schema; a first byte of `1`
is followed by an error as JSON. A path that the proxy or the server closes cleanly with no message
before the close states that the schema was not served.
