The server opens `/agent/dequeue` and sends no message. The proxy
withdraws every message in the queue, sends exactly one message, and
closes the connection. In the message, a first byte of `0` states that
the queue held one or more messages; a first byte of `1` states that
it was empty; a first byte of `2` is followed by an error as JSON.
For each message withdrawn, the proxy also sends `1` on that
message's own [`/agent/enqueue`](/proxy/agent/enqueue/) path.
