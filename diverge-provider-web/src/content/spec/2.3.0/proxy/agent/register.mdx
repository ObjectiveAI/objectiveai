The server opens `/agent/register` and sends one message, the request
below as JSON. The container answers with exactly one message — first
byte `0`, registered; or first byte `1` and the error's JSON — then
the close.

- **Once.** The agent is fixed for the container's life. A
  registration after a successful one is answered with an error. A
  loop asked for before a registration is answered with an error on
  [`/agent/run`](/proxy/agent/run/).
- **Not repeated.** A registration whose path ended abruptly has an
  answer the server did not hear; it is not asked again by anything
  here.
