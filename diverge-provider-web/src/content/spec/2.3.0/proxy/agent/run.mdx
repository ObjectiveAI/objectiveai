The server opens `/agent/run` and sends one message, the request
below as JSON, carrying the prompt. The container answers with the
loop.

```text
server → container:   [request JSON]                          once
container → server:   [0][chunk JSON] … [0][chunk JSON]       then the close
                   or [1][error JSON]                         then the close
                   or [0][chunk JSON] … [1][error JSON]       then the close
```

- **The first message decides.** An error as the first message
  states that no loop ran; a chunk as the first message states that
  one did. An error after chunks states that the loop ended without
  finishing, and is the last message.
- **A chunk is output.** A notification chunk marked fatal is the
  loop's own last word, a chunk and not an error, and the close
  follows it.
- **One loop at a time.** A loop asked for while one runs is
  answered with an error as the first message.
- **Not repeated.** A path that ended abruptly is a loop cut short;
  nothing here asks again.
