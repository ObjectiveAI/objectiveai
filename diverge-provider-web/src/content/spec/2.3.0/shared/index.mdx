A form or a procedure that more than one endpoint of the
[Endpoints](/endpoints/) layer carries is defined once, in its own
section of this layer. Each section states the form or the procedure
and the rules that are its own. It states nothing about which
endpoint carries it; the pages of the endpoints that carry it state
that, and link the section.

| Section | Defines |
|---------|---------|
| [Document](/shared/document/) | an image's `/DIVERGE.md`: the file, the JSON object a server sends for it, and what is not a document |
| [Possession](/shared/possession/) | the nonce check: the nonce, the image bytes, the proof, the `prove` ask and its answer, and the comparison |
