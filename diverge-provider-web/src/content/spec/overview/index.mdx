This specification is the protocol's normative definition.
[`diverge-provider-sdk`](https://docs.rs/diverge-provider-sdk) is a
Rust SDK that implements it, versioned with this specification's
revisions.

The whole specification is also available as
[a single page](/full/), as
[one plain-text file](/llms-full.txt), and section by section as raw
Markdown — every page links its own `.md` twin, and
[/llms.txt](/llms.txt) indexes them all. The crate and this site live
in [one repository](https://github.com/ObjectiveAI/objectiveai).
