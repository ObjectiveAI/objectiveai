The server opens `/tool/notifications` and sends nothing. The
container answers with one message per notification its MCP server
sends from then on, each the response frame below with first byte
`0` and the notification's JSON, for as long as the path lives. A
container whose MCP server cannot be reached answers one message —
first byte `1` and the error's JSON — then the close.

- **From then on.** Notifications sent before the path was opened
  are not delivered on it.
- **The server closes.** The path lives until the server closes it;
  the container closes it only for the error above.
