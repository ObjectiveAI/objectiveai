The server opens `/agent/dequeue` and sends nothing. The container
withdraws every message in the queue and answers with exactly one
message — `0`, the queue held messages; `1`, it was empty; or `2` and
the error's JSON — then the close. Each withdrawn message is also
answered `1` on its own [`/agent/enqueue`](/proxy/agent/enqueue/)
path.
