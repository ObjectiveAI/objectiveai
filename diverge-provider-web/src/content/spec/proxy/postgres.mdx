The ask is kind `11` on [`/requests`](/proxy/requests/), and its
payload is empty:

```text
[11]
```

It announces one connection the container has opened to its
database. The server opens `/postgres/{channel}`, and that path is
the connection.

- **Raw, both ways.** Every message in either direction is a chunk
  of the PostgreSQL wire protocol, verbatim: no frame, no tag, no
  acknowledgement. A pgwire message may span several WebSocket
  messages and several may share one; each party reassembles as it
  would from a socket. Nothing between the two ends reads the bytes.
- **The path is the connection.** The opening is the connection
  existing; the close, clean or abrupt and from either party, is the
  connection ending. There is no message that opens or closes it.
- **Before the path opens.** What the container's side wrote before
  the server opened the path is held and sent first, in order. An
  announcement whose `/requests` connection ended before its path was
  opened is a connection ended.
- **Nothing is repeated.** A connection that ended is not resumed
  and its bytes are not replayed; a new connection is a new
  announcement and a new path.
