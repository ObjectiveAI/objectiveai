The ask is kind `7` on [`/requests`](/proxy/requests/):

```text
[7][key …]
```

The server answers on `/vault/delete/{channel}` with exactly one
message, then the close. A path closed cleanly with no message is
the operation not served; an abrupt end is the operation failed, and
it is not asked again — see [Vault](/proxy/vault/).

The ask is `diverge-provider-sdk/src/shared/containers/vault/delete/request/request.rs`:

```rust include=diverge-provider-sdk/src/shared/containers/vault/delete/request/request.rs
```

The answer is the frame of [Vault](/proxy/vault/): `0` ok, or `1` and a message.
