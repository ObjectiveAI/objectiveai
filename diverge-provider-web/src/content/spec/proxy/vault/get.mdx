The ask is kind `5` on [`/requests`](/proxy/requests/):

```text
[5][key …]
```

The server answers on `/vault/get/{channel}` with exactly one
message, then the close. A path closed cleanly with no message is
the operation not served; an abrupt end is the operation failed, and
it is not asked again — see [Vault](/proxy/vault/).

- **Three answers.** `0` and the value, which may be empty; `1`, no
  value under the key; `2` and a message.
